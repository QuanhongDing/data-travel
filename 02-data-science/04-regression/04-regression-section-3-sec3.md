## 3. 设计模式与范式

### 3.1 先看约束：模式不是选择题，是约束的产物

场景决策表把设计讲成「按业务特征选一个算法」。真实的模式选择不是这样发生的：它被一组约束**推**着走——标签的可观测方式、预测值的用途（只要一个点还是要一个区间）、样本量与特征维度的比例、线上单请求预算、以及「结论要不要能写进决策文件」。同一条约束不同，同一业务场景下的正确模式就不同。

举一个直觉被推翻的例子：同一个「销量预测」需求，只要下游动作不同，模式就不同。下游按**均值**订货，MSE 训练的点估计最优；下游按**缺货成本与积压成本不对称**订货，最优决策点是一个高分位数，而不是均值——此时继续用均值模型不是「精度差一点」，而是系统性地把决策点锚在错误位置。

再一个：同一个「营销效果」需求，要「预测哪些人会买」是回归，要「预测给谁发券能多买到」是因果回归。这两者在数据结构上的差别是：后者必须存在处理变量与干预记录；没有干预数据时，前者不能冒充后者，因为回归系数估的是关联不是效应。

所以先立约束，再谈模式。下表是本主题下最容易被忽略的 6 条约束，以及它们各自推翻哪些直觉。

| 约束 | 它决定了什么 | 本主题下最容易被它推翻的直觉 |
| --- | --- | --- |
| 数据形态 / 标签来源 | 标签是连续可观测值、还是需要先判定「是否发生」再定金额；是否含文本/图像等非结构化信息 | 「预测一个数」一律是回归——含 0 值的金额类标签往往需要「先分类再回归」两段式 |
| 访问模式（离线批 / 在线点 / 多步外推） | 是训练一次批量出分，还是每次请求跑一次；是预测 1 步还是 30 步 | 「精度最高的模型就是最好的」——多步外推下误差会沿步长累积，训练目标的形状比离线精度更重要 |
| 变更频率与历史要求 | 特征口径与训练分布的稳定程度；是否需要周期性重训与可复现的版本 | 「一次调好就能长期用」——特征口径一变，旧模型进入静默失效，指标掉得不明显 |
| 一致性 / 可解释性要求 | 是否必须逐条给出「每个特征值多少钱」；结论是否要能通过审阅 | 「可解释=用线性回归」——线性模型只在你显式写入特征时才有正确的解释 |
| 规模与成本约束 | 样本量、特征维度、单请求延迟预算、GPU 与推理成本 | 「大数据就应该上深度学习」——样本量远小于模型容量时，深度模型的方差项主导误差 |
| 团队技能与运维能力 | 是否有人维护特征管线、重训调度、在线特征服务与监控 | 「模型上线就结束了」——回归的线上成本主要在特征管线与监控，不在训练代码 |

### 3.2 模式逐个拆解（核心节）

原文件列出 10 个模式，本节拆成 9 个小节：**贝叶斯回归（Bayesian）与分位数回归（Quantile）** 同为「输出分布而不是输出均值」，合并到 3.2.5 对比讲解，其余 8 个模式各占一节。每个模式给足约束、结构、机制、代价、失效点与真实使用。

#### 3.2.1 线性回归优先（Linear-First）

- **被什么约束逼出来**：结论必须能被逐条审阅——「这个特征每变化一个单位，输出变化多少」要能写进决策文件；同时样本量不足以支撑高容量模型。
- **结构**：

```text
线性回归优先（Linear-First）—— 结构 = 可加 + 线性的一层映射
  ŷ = w₀ + Σ_j w_j · x_j            特征「各自独立加总」进入预测
  三种开关，决定解的性质：
    MSE + λ‖w‖₂²              → Ridge（L2）：共线时把系数整体收缩，不置零
    MSE + λ‖w‖₁               → Lasso（L1）：把不重要的系数压到恰好 0（稀疏）
    MSE + λ₁‖w‖₁ + λ₂‖w‖₂²    → ElasticNet：相关特征成组进出
  特征侧：分箱 / 缺失指示列 / 手工交叉项（非线性必须由人显式写进来）
  ────────────────────────────────────────
  输出：一个点估计 ŷ + 一组可逐条审阅的系数 w_j
```

- **为什么有效（因果句）**：因为预测是特征的线性组合，所以单样本归因可以按 Σ w_j·x_j 逐项拆分、系数方向直接对应业务动作；代价是模型只能表达你写进特征的关系——所有交互与非线性都得由人预先构造。
- **代价**：维护面从模型转移到了特征。每一条业务假设（非线性、交互、分段）都要变成一个人工维护的列；特征数量随假设组合数增长，且新增列会改变已有系数的含义，历史结论不可直接比较。
- **失效点**：当特征接近共线（例如同时存在「订单数」「订单金额」「客单价」）时，「系数可逐条解释」会反转成「系数不可信」，因为 (XᵗX) 接近奇异，系数方差随条件数放大，预测值可能仍然稳定，但归因与政策建议已经失效——小扰动会让系数在相关特征之间大幅摆动。
- **真实使用**：受监管场景（信贷评分卡、保险定价）长期以分箱 + 线性/逻辑回归为主力【经验】，因为「每个特征的方向与幅度可被逐条审阅」是硬约束；工具侧 scikit-learn 与 statsmodels 是默认实现【公开】（可查其官方文档的线性模型与统计推断模块）。

#### 3.2.2 GBDT 主导（GBDT-Dominant）

- **被什么约束逼出来**：表格数据、样本量中等偏大、特征以数值与低基数类别为主，且团队没有 GPU 训练与在线深度模型运维能力——需要「不加深度网络也能拿到高精度」。
- **结构**：

```text
GBDT 主导（GBDT-Dominant）—— 结构 = 加性树的序列
  ŷ = Σ_{m=1..M} f_m(x)      f_m = 第 m 棵回归树，拟合上一轮的残差/梯度
  目标：Σ_i l(y_i, ŷ_i) + Σ_m Ω(f_m)      Ω = 叶子数惩罚 + 叶子权重 L2 惩罚
  关键开关：learning_rate（收缩步长）× M（树数）× max_depth/num_leaves
  ────────────────────────────────────────
  输入：数值 + 类别（CatBoost 原生处理类别；LightGBM 有类别特征支持）
  输出：一个点估计 ŷ，不含区间
  缺失值：树在分裂时自带默认方向，不需额外填补
```

- **为什么有效（因果句）**：因为每棵树只拟合上一轮预测的残差，所以单棵树的偏差可以很小、整体通过加总逼近任意光滑关系，同时不需要手工写交叉特征；代价是模型不再有「一个系数对应一个特征」的结构，解释只能退回到重要性排序与部分依赖曲线。
- **代价**：模型体积与推理延迟随树数与深度线性增长，线上要预留比线性模型大得多的内存与 CPU；跨机器一致性要求同一份模型文件与同一套特征计算代码，任何特征口径差异都会静默改变预测。
- **失效点**：当预测需要**外推**（超出训练标签取值域）时，「能拟合任意关系」会反转成「区间外是常数」，因为树的分裂点是训练数据里学到的阈值，超出最后一个分裂点的输入全部落到同一个叶子里——预测值被钉死在历史最大值附近，而不是继续跟随趋势。
- **真实使用**：XGBoost（Chen & Guestrin，KDD 2016）、LightGBM（Microsoft，2017）、CatBoost（Yandex，2018）是该模式的三个主流实现【公开】；结构化数据竞赛的榜单长期由 GBDT 类模型占据前列【经验】（可按竞赛名称自行查证当期榜单）。

#### 3.2.3 深度学习特化（DL-Specialized）

- **被什么约束逼出来**：特征是文本/图像/高基数 ID，人工交叉写不完；样本量足够大到能训练表征；线上有 GPU 或专用推理资源。
- **结构**：

```text
深度学习特化（DL-Specialized）—— 结构 = 表征学习层 + 回归头
  [原始输入]             [表征层]                  [回归头]
  文本/序列/ID 列  ──►  Embedding / Attention  ──►  若干全连接层  ──►  ŷ ∈ ℝ
                       （自学习特征交叉）            （线性输出，可加激活约束）
  ────────────────────────────────────────
  关键：网络同时承担「造特征」和「做预测」两件事
        线性输出层保证回归任务的值域不被人为限制
        训练侧：Mini-Batch 梯度下降 + Adam + 早停（按验证集）
```

- **为什么有效（因果句）**：因为表征层直接从原始输入学习交叉与相似度，所以不需要人工穷举特征组合，模型能利用「ID 之间是否相似」这类线性模型无法表达的信息；代价是把「调参—训练—部署」的复杂度整体抬高了一个量级。
- **代价**：训练与推理成本高（GPU 资源、模型服务化改造），调参空间大（学习率、层数、正则、批大小），且复现成本高——同一个配置换一次随机种子或数据顺序，效果差异可能落在业务可感知范围内【经验】。
- **失效点**：当样本量不足以支撑参数量时，「自动学特征」会反转成「学噪声」，因为参数量远大于有效信息量时，训练过程会优先拟合训练集中的偶然相关性，验证集误差随训练轮数先降后升——此时加训练轮数只会让它更差。
- **真实使用**：Uber 公开过用深度学习做到达时间预估（DeepETA）的工作【公开】（Uber Engineering Blog，2022），其价值在于融合大量时空上下文；亚马逊的 DeepAR 用自回归 RNN 做多序列时序预测【公开】（Salinas 等，International Journal of Forecasting，2020）。

#### 3.2.4 时序专用（TS-Specialized）

- **被什么约束逼出来**：预测目标本身带时间结构——趋势、季节性、节假日效应，且需要多步外推（未来 7/30/90 天），而普通回归的样本是「独立同分布」假设。
- **结构**：

```text
时序专用（TS-Specialized）—— 结构 = 把时间显式拆成可加分量
  加法模型（Prophet 风格）：
    y(t) = 趋势 g(t) + 季节性 s(t) + 节假日 h(t) + 误差 ε(t)
  自回归 / 状态空间（ARIMA 风格）：
    y_t = c + Σ_{i=1..p} φ_i y_{t-i} + Σ_{j=1..q} θ_j ε_{t-j} + ε_t
          （AR：用历史值；MA：用历史残差；I：先差分去趋势）
  ────────────────────────────────────────
  关键差别：输入里包含「该序列自己的历史」，
            而不是一堆横截面特征
  评估：必须按时间前向切分，不能用随机 K-Fold
```

- **为什么有效（因果句）**：因为模型把「去年同期」「上期残差」显式作为输入，所以趋势与周期结构被参数化而不是被当成噪声；代价是它对横截面特征（促销、价格、竞品）的表达能力弱于通用回归，需要额外的回归项才能纳入。
- **代价**：每个序列（或每组序列）都要有自己的参数与检验流程（平稳性、阶数选择、异常点处理），序列数量一多，维护面按序列数放大；节假日这类日历效应需要人工维护日历表，日历表过期即静默出错。
- **失效点**：当发生结构性断点（政策变化、渠道迁移、疫情级别的需求跳变）时，「历史模式可外推」会反转成「历史模式把预测拉回旧水平」，因为自回归项把最近的极端值当作未来会重复的信号，趋势项需要若干周期才能跟上。
- **真实使用**：Prophet（Taylor & Letham，The American Statistician，2018）以「分析师可手调的分量模型」为定位被广泛用于业务基线预测【公开】；零售与供应链场景通常先跑该类加法模型做基线，再判断是否值得上更复杂的模型【经验】。

#### 3.2.5 贝叶斯回归（Bayesian）与分位数回归（Quantile）——预测分布

两者被同一个约束逼出来：**下游决策用的不是均值，而是一个区间或一个分位点**。贝叶斯回归输出参数的**后验分布**并据此给出预测区间；分位数回归直接以非对称损失训练出第 τ 分位数。

- **结构**：

```text
预测分布的两条路线（都输出「范围」而不是「一个数」）
  ① 贝叶斯：参数有先验，输出后验
     w ~ N(0, σ_w²I)          ← 先验
     y ~ N(wᵗx, σ_n²)         ← 似然
     w|X,y ~ N(μ_post, Σ_post)  Σ_post⁻¹ = σ_n⁻²XᵗX + σ_w⁻²I
     预测区间 = 由后验积分得到（含参数不确定性）
  ② 分位数：直接改损失，训练 τ 分位
     L_τ = Σ_{y≥ŷ} τ(y-ŷ) + Σ_{y<ŷ} (1-τ)(ŷ-y)
     训练 τ=0.9 得到的是「90% 的样本低于它」的预测值
  ────────────────────────────────────────
  关键差别：① 连参数的不确定性一起建模；② 只关心输出的尾部位置
```

- **为什么有效（因果句）**：因为损失函数不再是「误差平方」，所以最优解从条件均值变成了条件分位数（或整个后验），模型能回答「最坏情况下大概多少」；代价是少了 MSE 那套成熟的诊断工具，评估要改成区间覆盖率、分位损失这类指标。
- **代价**：贝叶斯路线的计算成本高出一个量级（MCMC 采样或变分推断），且要维护先验假设——先验选错时，小样本下的结论会带着看不见的偏；分位数路线要为每个目标分位训练一个模型（或改造成多目标），模型数量与分位点数成正比。
- **失效点**：当分位数由**多个独立单分位模型**分别预测时，「尾部可控」会反转成「分位交叉」——出现 90 分位预测值低于 80 分位预测值，因为各模型独立训练、彼此没有单调性约束；下游按这些分位做库存或风险决策时，会得到互相矛盾的行动建议。
- **真实使用**：LightGBM 与 XGBoost 都提供分位数目标函数【公开】（可查其官方文档中 objective 的可选值）；PyMC、Stan、GPyTorch 是活跃的贝叶斯实现【公开】。库存备货取高分位、风险预警取尾部是通用做法【经验】，具体分位取值应由缺货成本与积压成本的比值推出，而不是照搬。

#### 3.2.6 因果回归（Causal）

- **被什么约束逼出来**：决策不是「预测多少」，而是「如果我干预，结果会变成什么」——需要回答异质处理效应（这个人群的增量是多少），而观测数据里处理变量与结果共享混淆变量。
- **结构**：

```text
因果回归（Causal）—— 结构 = 输出模型 + 处理模型 + 效应估计
  目标：τ(x) = E[Y(1) - Y(0) | X = x]        （CATE，个体/条件处理效应）
  Meta-Learner 的两种拼法：
    T-Learner：分别训练 M₁(x)≈E[Y|T=1] 与 M₀(x)≈E[Y|T=0]，τ̂ = M₁(x) - M₀(x)
    X-Learner：先估倾向得分 e(x)=P(T=1|x)，再用 e(x) 加权组合两个效应估计
  DML / 双机器学习：
    Ŷ = f(X, T) 与 e(X) 分别用 ML 估计（nuisance），
    再用残差回归估 τ —— 避免把混淆效应算进处理效应
  ────────────────────────────────────────
  前提：必须有处理变量 T 与干预记录；
        没有干预数据时只能用实验/工具变量/断点来补
```

- **为什么有效（因果句）**：因为模型把「处理」作为一个独立变量并对混淆结构显式建模（倾向得分或残差正交化），所以估出的是干预的增量而不是关联，能直接支撑「该给谁发券」这类动作；代价是它依赖识别假设，假设不成立时结论无法从数据内部自证。
- **代价**：数据要求高（要有干预记录、倾向得分不能接近 0 或 1、重叠假设要成立），方法复杂度高（自研因果代码、验证靠模拟数据与安慰剂检验），且结论无法像预测精度那样用单一指标验收。
- **失效点**：当处理组与对照组的协变量分布几乎不重叠时，「异质效应可估」会反转成「区间内插值、区间外外推」，因为倾向得分接近 0/1 的样本没有可比的对照，τ̂(x) 在那部分人群上完全由模型形式决定，而不是由数据决定。
- **真实使用**：Causal Forest（Wager & Athey，JASA 2018）与 Double Machine Learning（Chernozhukov 等，The Econometrics Journal 2018）是该模式的两篇奠基工作【公开】；增长与营销团队普遍用 T-Learner / X-Learner / Causal Forest 做增量建模【经验】，通常与随机实验并行：先做实验定因果方向，再用因果模型做人群细分。

#### 3.2.7 混合架构（Hybrid）

- **被什么约束逼出来**：业务信号同时含「可解释的结构项」（趋势、季节、促销乘子）和「说不清但确实存在的非线性」（长尾交互），单一模型两头都要丢一部分。
- **结构**：

```text
混合架构（Hybrid）—— 结构 = 按信号来源分工，再相加或叠乘
  销量 = 趋势(t) × 季节(t) × 促销乘子 × exp(残差模型(x))
                │                        │
        线性/加法模型负责：           GBDT 负责：
        · 整体趋势与周期性            · 剩余的非线性交互
        · 业务可解释的乘子            · 难以人工写出的组合
  ────────────────────────────────────────
  关键：分工边界必须是「业务上说得通的分工」，
        不是「随便切一刀让两个模型拼起来」
  残差模型的上限：只负责趋势/季节解释不了的部分
```

- **为什么有效（因果句）**：因为结构项由业务可解释的模型承担、残差项由高容量模型吸收，所以整体预测兼顾了外推（趋势项可以外推）与拟合（树项拟合局部）；代价是误差归因被拆成两段，排障时要先判断是「趋势项错了」还是「残差项错了」。
- **代价**：两个模型、两套训练与两个版本，任一环节变更都要重跑联合评估；线上推理要么串行两段（延迟相加），要么离线预计算残差项（时效性受限）。
- **失效点**：当残差模型被喂进了本应属于趋势项的信息（例如把时间索引直接作为树的特征）时，「分工协作」会反转成「两个模型学同一个东西」——树项把趋势也学走，外推时两段预测同时给出同方向的外推，误差被放大而不是被补偿。
- **真实使用**：多任务场景下 MMoE（Ma 等，KDD 2018，在 YouTube 推荐上验证）与 PLE（Tang 等，RecSys 2020，腾讯）是「共享底层 + 任务专属上层」的代表结构【公开】；另一种常见拼法是「时序结构项 + GBDT 残差」【经验】。

#### 3.2.8 物理信息回归（PINN）

- **被什么约束逼出来**：数据稀缺但物理规律已知（守恒律、传热/结构方程），纯数据驱动会给出违反物理的预测，而数值仿真又贵到不能逐次调用。
- **结构**：

```text
物理信息回归（PINN）—— 结构 = 网络输出 + 方程残差共同进损失
  ŷ = NN(x, t)                     网络拟合场量（温度、位移、浓度）
  L = L_data + λ · L_phys
        L_data  = Σ |ŷ - y_obs|²                    只在有观测的点上
        L_phys  = Σ |N[ŷ](x,t)|²                    在配点上算方程残差
                  N = 微分算子（如 ∂u/∂t - α∇²u）
  边界/初值条件：作为一个额外的损失项加入
  ────────────────────────────────────────
  关键：物理不是后处理约束，而是损失函数的一部分
        → 数据点稀疏时，配点把解「撑」在物理合理的形状上
```

- **为什么有效（因果句）**：因为方程残差进入了损失函数，所以模型即使在无观测区域也被物理约束牵引，泛化不再只依赖观测点密度；代价是损失里多了权重 λ 与配点采样策略这两组没有理论最优解的超参。
- **代价**：训练成本高（每个配点都要算自动微分）、调参难（数据项与物理项的权重失衡时，要么物理失效要么数据被忽略）、工程栈重（需要自动微分框架与微分算子实现）。
- **失效点**：当数据量与物理项权重失衡时，「物理约束提升泛化」会反转成「物理项主导、观测被忽略」——模型收敛到一个处处满足方程但与实际观测有系统偏差的解，因为损失对数据误差的梯度被 λ 压制。
- **真实使用**：PINN 由 Raissi、Perdikaris、Karniadakis 提出【公开】（Journal of Computational Physics，2019）；DeepXDE 等库提供了该模式的实现【公开】（可查其官方文档与示例）。工程仿真与科学计算场景采用较多【经验】。

#### 3.2.9 LLM 增强（LLM-Augmented）

- **被什么约束逼出来**：信息主源是长文本（评论、商品描述、工单），人工把它变成特征列既慢又覆盖不全，而样本量又不足以自训一个文本模型。
- **结构**：

```text
LLM 增强（LLM-Augmented）—— 结构 = 两条流水线在特征层汇合
  [文本：评论 / 商品描述 / 工单]
        │  LLM 离线批处理（不是在线的逐次调用）
        ▼
  向量（embedding）或有序标签分数（如 1–5 分）
        │  降维 / 池化 / 与结构化列拼接
        ▼
  [结构化特征表] ──► GBDT 或线性回归 ──► ŷ
  ────────────────────────────────────────
  关键边界：LLM 只负责「把文本变成数」，回归器负责「把数变成预测」
            在线只跑回归器 → 文本侧成本被离线摊薄
```

- **为什么有效（因果句）**：因为文本语义被压缩成固定维度的数值向量，所以回归器能用上人工写不出来的语义信息，而不需要在线上承担模型调用延迟；代价是把模型的失效面扩大到了两段管线——文本侧换一次提示词或模型版本，特征分布就整体漂移一次。
- **代价**：两段管线的版本管理（提示词、LLM 版本、向量维度、回归模型），离线批处理的成本与延迟，以及「LLM 输出本身带噪声」这一无法在回归层消除的问题。
- **失效点**：当 LLM 侧升级（换版本、改提示词、加思考步骤）时，「语义特征稳定」会反转成「特征分布整体漂移」——同一段文本在升级前后得到的向量或分数系统性偏移，回归器是在旧分布上训练的，预测会整体偏移而监控指标（如输入长度、非空率）完全正常，故障只能从预测分布本身发现。
- **真实使用**：LLM 输出作为特征再喂给传统回归器是当前「文本影响数值」的主流工程做法【经验】；也可直接用 LLM 对主观维度打分生成回归标签，再据此训练小模型【经验】——后者的前提是抽样人工校准，否则标签噪声会被回归器当作信号学走。

### 3.3 模式选择决策表

| 约束组合 | 推荐模式 | 为什么不选另一个 | 关键判据 |
| --- | --- | --- | --- |
| 低维 + 线性关系 + 可解释 | 线性回归优先（OLS/Ridge/Lasso） | 不选 GBDT：树的归因是分段常数，给不出「每单位特征值多少钱」 | 结论要能逐条审阅，且特征数远小于样本数 |
| 表格数据 + 中等规模 | GBDT 主导 | 不选 DL：同等精度下 GBDT 无 GPU 依赖、调参面小 | 特征以数值与低基数类别为主，样本量中等到大 |
| 高维 + 大数据 + 强非线性 | 深度学习特化 | 不选 GBDT：人工交叉写不完，需要模型自己学表征 | 有 GPU 与在线推理资源，样本量足以支撑参数量 |
| 强时序依赖 + 季节性 | 时序专用 | 不选普通回归：它的样本假设里没有「时间」 | 有明确周期/节假日效应，且需要多步外推 |
| 需要不确定性估计 | 贝叶斯回归 / 分位数回归 / Conformal | 不选点估计模型：点估计的输出里没有区间这个字段 | 下游按分位决策，或结论需要置信区间 |
| 异质处理效应 / 因果推断 | 因果回归（Causal Forest / Meta-Learner / DML） | 不选普通回归：回归系数估的是关联，混淆会污染它 | 有处理变量与干预记录，决策要回答「对谁有效」 |
| 90 分位 / 风险预警 | 分位数回归 | 不选均值回归：均值给不出尾部位置 | 成本函数非对称（缺货 ≠ 积压） |
| 长文本数值预测 | LLM 增强（Embedding + 回归头/GBDT） | 不选纯 GBDT：文本语义无法人工穷举成特征列 | 文本是信息主源，样本量不足以自训文本模型 |
| 实时性要求高 | 线性 / FM / 双塔等轻模型 | 不选 GBDT/DL：单请求延迟预算内跑不完 | P99 预算在毫秒级，且有在线特征服务 |
| 物理约束场景 | 物理信息回归（PINN） | 不选纯数据驱动：物理定律被当成可从数据里学的噪声 | 有可写成微分方程或守恒律的先验 |
| 分布漂移明显 | 在线学习 / 鲁棒回归 | 不选静态训练：训练分布与线上分布已经不是同一个 | 有可用的新标签回流，且漂移可检测 |
| 数据极少 | Ridge / Bayesian Ridge | 不选 GBDT/DL：模型容量远超现有信息量 | 样本量不足以支撑高容量模型，需要先验兜底 |
| 多任务联合 | MMoE / PLE 等多任务结构 | 不选单任务各自建模：任务间共享的信号被浪费 | 任务相关但不完全一致（如 CTR 与 CVR） |
| 自变量有强异方差 | WLS / GLS | 不选 OLS：同方差假设不成立时标准误是错的 | 残差方差不齐，且需要显著性判断 |
| 含分类特征多 | CatBoost | 不选独热编码 + 其他 GBDT：高基数独热后维度爆炸 | 类别基数高，类别间有顺序或组合关系 |
| 高维稀疏（文本词袋类） | Embedding + LightGBM | 不选纯线性：稀疏线性表达不了交互 | 特征数远大于样本数，但每样本非零值很少 |

表中的「数据极少」「高基数」等是量级启发式，不是定理边界【经验】：真正的判据是「有效信息量 vs 模型容量」，而不是某一个样本数阈值。

本主题下**最常被误选的一对是「GBDT 主导」与「深度学习特化」**。误选的实际后果分两种：样本量不足时上深度模型，是拿参数量去拟合噪声——验证集误差比同特征下的 GBDT 更差，而团队会把原因误判为「调参不到位」，继续加训练轮数与容量；样本量足够但线上延迟预算紧时上深度模型，是给了一个离线指标略好、线上 P99 超预算的模型，最后被迫回退到轻模型或加缓存层，返工成本主要落在推理链路改造上。第二常见的误选是**「时序专用」与「普通回归」**：把带时间结构的预测当成普通回归做，离线指标常常还挺好看（因为有滞后特征泄漏），上线后才暴露。

### 3.4 组合模式：真实系统不会只用一种

**组合一：加法结构项 × GBDT 残差。** 分工边界是「趋势与周期归结构项，剩下的一切归树」；运维代价是两个模型两套版本、排障时先判归属再查特征；适合的规模是有多步外推需求、且趋势不可由树模型承担的场景。

**组合二：点估计 × 分位数（多目标）。** 用同一份特征同时训练均值目标与 1–2 个分位目标，分工边界是「均值给报表，分位给决策」；运维代价是模型数量与评估口径同时增加（MAE/RMSE 加区间覆盖率、分位损失）；适合的规模是有明确非对称成本、且下游决策真的会按分位执行的团队。若分位只是「顺便报一下」，不值得付这份代价。

**组合三：因果 × 预测（两段式）。** 先用实验或工具变量定因果方向与整体效应，再用 CATE 模型做人群细分，预测模型只用于选触达时机；分工边界是「因果模型决定对谁、预测模型决定何时」；运维代价是同时维护实验平台与因果建模能力，且两者的人群口径必须对齐；适合的规模是营销/补贴类决策，且干预成本高到「发错人」有真实损失。

### 3.5 反模式与失效分析

原文件列出的 12 条反模式全部保留，逐条补齐「症状 → 后果 → 成因 → 修法」。

| 反模式 | 症状（怎么发现它） | 后果（机制层面的后果） | 成因（为什么团队会写成这样） | 修法 |
| --- | --- | --- | --- | --- |
| 特征工程不到位就上深度学习 | 训练 loss 持续下降，验证集纹丝不动，特征侧只有原始数值列 | 网络容量被用来拟合训练集的偶然相关性，方差项主导误差 | 「深度=先进」的选型惯性，把调参当成唯一提升手段 | 结构化数据先用 GBDT 打基线，确认精度不足且样本量足够后再上 DL |
| 用 accuracy 评估回归 | 评估报告里出现「准确率 87%」 | 连续值逐点相等命中率极低且对误差量级不敏感，指标与误差无关 | 从分类任务直接搬来的评估模板 | 改用 MAE / RMSE / R² / MAPE，加业务指标（库存成本、毛利误差） |
| 不考虑业务量纲 | 模型 MAE 很小，但业务抱怨「大单全部预测偏低」 | 绝对损失对所有样本同权，而业务成本函数对不同量级样本不同权 | 损失函数与业务成本表从未对齐过 | 用样本权重或自定义损失，把业务成本写进目标函数 |
| MAPE 在 y=0 附近失效 | 指标出现 inf 或异常大值，且集中在含 0 的样本上 | MAPE 的分母是真实值，分母为 0 时该项发散 | 把相对误差指标当万能指标 | 改 SMAPE；或拆成两段式（先判是否发生，再预测金额） |
| 过拟合靠加大模型容量 | 训练指标持续改善，验证指标随容量上升先降后升 | 加容量是降偏差、抬方差；过拟合是方差问题，方向反了 | 把「模型不够强」一律当成欠拟合 | 正则化（L1/L2/Dropout）+ 早停 + 交叉验证 + 更多有效特征 |
| 不区分训练 / 验证 / 测试集（时序泄露） | 离线 R² 很高，上线效果接近随机或大幅衰减 | 随机切分让未来样本进入训练集，模型学到线上不存在的未来信息 | 沿用横截面数据的随机切分习惯 | 按时间前向切分，特征只在训练窗口内可见 |
| 线性回归直接上原始特征 | 系数符号与业务常识相反，残差呈 U 形 | 未写入的交互与非线性被残差吸收，转而污染全部系数 | 把「可解释」误解为「不需要做特征工程」 | 分箱 / 多项式 / 交叉项 / 样条，把非线性显式写进特征 |
| 外推完全失败 | 预测值超出历史值域数个量级，或全部贴在历史极值上 | 树在训练区间外是常数，线性模型是无限外延的直线，两者都不含「趋势会变」 | 只用内插验证集评估，从未测过区间外 | 约束输出域、加入趋势/物理结构，或换带趋势项的时序模型 |
| 时序数据用普通回归 | 模型里看不到「上期销量」这个最重要的输入 | 时间依赖未被建模，样本被当作独立同分布，残差里全是可利用的自相关 | 把「回归」和「预测」当同义词 | 加滞后/滚动特征，或改用 ARIMA / Prophet / 时序 Transformer |
| 因果关系当相关关系用 | 结论是「投放越多销量越高」，但实际可能是销量高的品被多投 | 观测数据里处理变量与结果共享混淆变量，系数估的是关联 | 相关与因果的差别在流程里被跳过 | 实验/工具变量/断点/差分设计，或用因果回归与 DML 显式建模混淆 |
| 不处理异常值 | 少数极端样本主导损失与系数，去掉几条数据结论就变 | 平方损失对误差的惩罚是二次的，量级大的点权重压倒性 | 把异常值一律当成必须保留的真实信号 | Huber Loss / Winsorize（缩尾）/ 先判定异常再决定保留或修正 |
| 预测平均值不用分位数 | 备货按均值算，缺货与积压同时发生 | 均值最优只对对称平方损失成立；成本非对称时，均值不是最优决策点 | 「预测=给一个数」的默认心智 | 分位数回归 / 贝叶斯 / Conformal，按目标分位训练与评估 |

三条最危险的反模式，在生产中的典型暴露方式：

**「不区分训练/验证/测试集（时序泄露）」** 的暴露方式是「上线第一天就崩，而离线报告毫无异常」。机制是这样的：随机切分把 T+7 的样本放进了训练集，如果特征侧还包含滚动均值、近 7 天计数这类特征，那么训练样本的一部分特征值就是由未来算出来的；离线评估恰好看上去很好，因此没有任何人会在上线前质疑它。识别方法很简单——把切分方式换成按时间切分，如果指标出现断崖式下跌，说明之前一直在靠泄露撑着。

**「因果关系当相关关系用」** 的暴露方式是「预算花出去了，自然量没涨」。典型形态是反向选择：好卖的品自然得到更多投放，回归系数因此为正且很大；上线后按系数把预算加到「历史销量高」的人群，发现增量接近零，因为这些人本来就会买。识别方法是问一句「这个结论有没有来自随机实验、断点或工具变量的证据」，如果只有观测数据回归，那这条结论只能用于描述，不能用于干预。

**「外推完全失败」** 的暴露方式是「大盘整体换挡时，模型给出的预测落在历史区间里不动」。树模型在训练区间外的输出是常数，线性模型会给出一个方向固定、斜率固定的外推；如果业务正在经历渠道迁移或价格结构性调整，两种模型的预测都会系统性偏离，而模型监控看的往往是输入特征是否正常（它们确实正常）。兜底做法是给预测值加上限截断并保留一条基线规则，让失效时表现为「预测保守」而不是「业务事故」。

### 3.6 规模跃迁时模式何时该换

模式不是一劳永逸的。样本量、特征维度、预测步长、任务数跨过某个量级时，原来正确的模式会开始产生结构性错误。

| 跃迁 | 原模式 | 为什么开始疼 | 换成 | 迁移的代价 |
| --- | --- | --- | --- | --- |
| 样本量从很小涨到中等 | 线性回归优先 | 特征组合数随业务假设爆炸，人工写交叉项写不过来 | GBDT 主导 | 把「特征含义可沟通」换成「模型不透明需评审」的治理成本 |
| 高基数类别特征变多 | GBDT（独热编码） | 独热后维度爆炸，训练时间与内存超预算 | CatBoost / Embedding + GBDT | 需要重建特征存取管线与向量/编码服务 |
| 从预测 1 步到多步外推 | 单点回归 | 递归外推误差沿步长累积，越往后越偏 | 时序专用（多步直接预测结构） | 特征与评估流程重写，评估从单点误差改为多步误差曲线 |
| 从单任务到多任务 | 每任务一套独立模型 | 任务间共享信号被浪费，模型数量与维护面按任务数增长 | MMoE / PLE 等多任务结构 | 训练与线上推理链路改造，任务间权重需要调 |
| 从「报一个数」到「按分位决策」 | MSE 训练的点估计 | 成本非对称时均值不是最优决策点，缺货与积压同时发生 | 分位数回归 / 贝叶斯 | 多模型或多目标训练，评估口径换成区间覆盖率与分位损失 |
| 从「预测」到「干预」 | 预测模型 + 系数解释 | 系数被当成因果效应用于报价、补贴与配额分配 | 因果回归 / DML，并配实验平台 | 需要干预数据与因果建模能力，验收标准从精度变为识别假设检验 |

### 3.7 自检清单

- [ ] 目标变量是否被定义为「可观测的连续量」？若是「是否发生」，你实际在做分类，回归只是其中一种编码。
- [ ] 损失函数是否与业务成本同向？若缺货与积压成本不对称却用 MSE 训练，说明损失选错了。
- [ ] 评估指标里是否出现过 accuracy？出现即违反——回归必须用 MAE / RMSE / R² / MAPE 加业务指标。
- [ ] MAPE 的分母是否可能为 0？存在 y=0 的样本就必须换 SMAPE 或改两段式建模。
- [ ] 时序任务是否按时间前向切分？出现随机 K-Fold 即等于把未来信息泄露进训练集。
- [ ] 训练特征与线上特征是否同源同口径？口径不一致时先查特征管线，再怀疑模型。
- [ ] 预测值是否被约束在物理可能范围内（非负、不超容量）？未约束的模型会给出负销量或超上限的预测。
- [ ] 是否报告了点估计之外的不确定性？下游按分位决策却没有区间，等于把尾部风险外包给业务。
- [ ] 因果结论是否有实验、工具变量或断点支撑？只有观测数据回归就宣称因果，属最高风险项。
- [ ] 异常值处理与损失函数是否匹配？未做 Huber / Winsorize 时，MSE 会被极端值主导。
- [ ] 是否有模型之外的兜底（上下限截断、回退基线、人工复核）？这决定外推失效时是「预测难看」还是「业务事故」。

### 3.8 小结

| 你的约束 | 建议模式 | 关键理由（机制层面） |
| --- | --- | --- |
| 结论要能逐条审阅，样本量有限 | 线性回归优先 | 单样本归因可按线性项拆分，代价是特征必须人工构造 |
| 表格数据、要精度、不要 GPU | GBDT 主导 | 残差加性拟合任意关系，代价是区间外输出为常数 |
| 高维 ID / 文本、样本量足够 | 深度学习特化 | 表征层自学习交叉，代价是参数量与调参面同时上升 |
| 多步外推、有周期结构 | 时序专用 | 时间分量被显式参数化，代价是序列数放大的维护面 |
| 决策按区间或分位 | 贝叶斯 / 分位数回归 | 损失非对称时最优解不在均值处，代价是多模型与分位交叉风险 |
| 决策是干预而非预测 | 因果回归 / DML | 混淆被显式建模，代价是识别假设无法从数据内部自证 |
| 文本是信息主源 | LLM 增强 + GBDT | 语义被压缩成数值特征，代价是两段管线的版本耦合 |

> 本节小结：本主题下**决定模式选择的唯一那条约束，是「预测值将被用来做什么动作」**——报表用于描述、分位用于订货、因果用于补贴、外推用于长期规划，四种用途对同一份数据的正确模型完全不同；离线精度只是这条约束下的一个验收项，不是选型的起点。
