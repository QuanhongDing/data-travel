### 6.1 某头部电商"**广告出价 Contextual Bandit + PPO**"5+ 年（2019-2024）

**背景（Why）**

该电商 2019 年面临**广告出价的探索-利用难题**：
- **日均 10 亿次广告展示**——**每次展示都要在 < 50ms 内出价**
- **静态出价失效**——同一个人不同时间价值不同（**早 8 点 vs 晚 11 点**），同一个人不同位置价值不同
- **新广告主无数据**——历史出价模型直接挂
- **业务目标多元**——CTR / CVR / ROI / GMV 需要**联合优化**

**触发点（What）**

2019 年该电商启动 RL 广告出价（[案例 2019]），目标：
- **eCPM**——**+15%**
- **广告收入**——**年增 8 亿+**
- **新广告主**——**有起量能力**

**详细做法（How）**

该电商广告出价 RL 的**5 大核心组件**：

1. **Contextual Bandit（核心创新）**
   - 关键设计：**以「(用户特征, 上下文) → 出价」为单位做探索-利用**
   - 关键能力：**在不确定中找最优**
   - 关键数字：**eCPM +15%**
   - 关键示意：
     ```python
     # UCB1 选择
     q_a = mu_a + sqrt(2 * log(total_pulls) / pulls_a)
     action = argmax(q_a)  # 探索 - 利用平衡
     # 反馈：用户点击 → +reward 1；不点 → 0
     # 在线实时更新 mu_a / pulls_a
     ```

2. **Deep RL (PPO)（核心）**
   - 关键设计：**Policy Network 直接出价**，**Critic 网络评估长期价值**
   - 关键能力：**连续动作空间 + 长期价值**
   - 关键数字：**广告收入年增 8 亿+**

3. **自研 RL 平台（核心）**
   - 关键设计：**训练 / 部署 / 监控一体化**
   - 关键能力：**千广告主独立优化**
   - 关键数字：**平台承载 100+ 场景**

4. **实时决策引擎（核心）**
   - 关键设计：**请求来了 → 实时推理 → 出价**
   - 关键能力：**P99 < 50ms**
   - 关键数字：**QPS 10 万+**

5. **探索-利用平衡（核心创新）**
   - 关键设计：**Thompson Sampling** + **Contextual Bandit** 双轨
   - 关键能力：**新广告主也能探索**
   - 关键数字：**新广告主起量时间 -50%**

**该电商广告出价 RL 关键数字**（[案例 2019-2024]）：

| 指标 | 改前 | 改后 | 提升 |
| --- | --- | --- | --- |
| **eCPM** | 基线 | +15% | **+15%** |
| **广告收入** | 基线 | 年增 8 亿+ | **8 亿+** |
| **P99** | 100ms | < 50ms | **-50%** |
| **QPS** | 不可用 | 10 万+ | **∞** |
| **Contextual Bandit** | 不可用 | 100% | **∞** |
| **PPO** | 不可用 | 100% | **∞** |
| **新广告主起量** | 基线 | -50% | **-50%** |
| **10 亿次/日** | 不可用 | 100% | **∞** |

**具体数字（How much）**

- 团队规模：该电商广告 RL 团队 50+ 人
- 关键数字：**eCPM +15%**；**广告收入年增 8 亿+**；**QPS 10 万+**
- 业务影响：覆盖该电商**日 10 亿次广告展示**

**失败教训**

- 早期「**eCPM 低**」——静态出价无法适应个性化，倒逼 Contextual Bandit + PPO
- **探索过激**——纯 UCB1 一开始探索过度，**短期收入下降 30%**；后改为**「保守开局 → 探索逐步加码」**
- **奖励函数设计错**——只看点击，**广告主 ROI 暴跌**；后改为**「广告主 7 日 ROI」作为奖励**

### 6.2 某短视频平台"**推荐重排 监督 + RL**"5+ 年（2019-2024）

**背景（Why）**

该短视频 2019 年面临**短期 CTR 饱和的长期价值问题**：
- **亿级用户**——**短期 CTR 已饱和**（继续优化 +0.5% 都难）
- **多刷几条**——**长期 GMV / 留存才是关键**
- **监督学习做不了**——监督信号只看「点不点」，**不看「多刷几分钟」**

**触发点（What）**

2019 年该短视频启动**RL 重排**（[案例 2019]），目标：
- **长期 GMV**——**+8%**
- **用户活跃**——**+5%**

**详细做法（How）**

该短视频重排 RL 的**5 大核心组件**：

1. **监督学习粗排（核心创新）**
   - 关键设计：**短期 CTR 仍由监督学习管**（稳定 baseline）
   - 关键能力：**不动粗排**
   - 关键数字：**基线稳定**

2. **RL 重排（核心）**
   - 关键设计：**重排阶段用 RL**——奖励 = 长期 GMV - 短期点击
   - 关键能力：**平衡短期与长期**
   - 关键数字：**长期 GMV +8%**

3. **多目标 RL（核心）**
   - 关键设计：**点击 / 完播 / 点赞 / 关注 各自权重**
   - 关键能力：**业务目标可调**
   - 关键数字：**多目标 +6%**

4. **离线模拟器（核心）**
   - 关键设计：**用户行为模拟器 + 策略 A/B 模拟**
   - 关键能力：**上线前评估**
   - 关键数字：**模拟器决策与线上吻合率 92%**

5. **自研 RL 平台（核心创新）**
   - 关键设计：**监督 / 离线 RL / 在线 RL 三阶段流水线**
   - 关键能力：**快迭代**
   - 关键数字：**训练 → 部署 < 1 天**

**该短视频重排 RL 关键数字**（[案例 2019-2024]）：

| 指标 | 改前 | 改后 | 提升 |
| --- | --- | --- | --- |
| **长期 GMV** | 基线 | +8% | **+8%** |
| **用户活跃** | 基线 | +5% | **+5%** |
| **多目标** | 不可用 | +6% | **∞** |
| **离线模拟器吻合** | 不可用 | 92% | **∞** |
| **Contextual Bandit** | 不可用 | 100% | **∞** |
| **训练-部署** | 不可用 | < 1 天 | **∞** |
| **监督 / RL 三阶段** | 不可用 | 100% | **∞** |

**具体数字（How much）**

- 团队规模：该短视频重排 RL 团队 50+ 人
- 关键数字：**长期 GMV +8% / 活跃 +5%**；**多目标 +6%**；**模拟器 92%**
- 业务影响：覆盖该短视频**亿级用户**

**失败教训**

- 早期「**短期饱和**」——只盯 CTR，**长期留存掉**；倒逼**「监督粗排 + RL 重排 + 长期 GMV 奖励」**
- **没有离线模拟器**——第一版直接上 AB，**事故造成 5% 时长下降**；后必须**模拟器过关才上 AB**
- **奖励函数过单一**——只奖励 GMV，**用户体验指标下滑**；后改为**多目标奖励（GMV + 活跃 + 完播）**

### 6.3 某出行公司"**动态定价 Contextual Bandit**"4+ 年（2020-2024）

**背景（Why）**

该出行公司 2020 年面临**多目标动态定价**：
- **实时供需匹配**——价格要随供需变化
- **多目标**——**收入 + 用户体验 + 司机收入**，三难
- **非平稳环境**——**早高峰 vs 深夜、下雨天 vs 晴天**定价策略差异巨大
- **冷启动**——**新司机 / 新城市无数据**

**触发点（What）**

2020 年该出行公司启动**动态定价 RL**（[案例 2020]），目标：
- **订单匹配率**——**+10%**
- **用户 / 司机满意度**——**+5%**
- **新城市冷启动**——**< 1 周**

**详细做法（How）**

该出行公司动态定价 RL 的**5 大核心组件**：

1. **Contextual Bandit（核心创新）**
   - 关键设计：**(城市, 时段, 天气, 供需) → 溢价倍数**
   - 关键能力：**高维上下文**
   - 关键数字：**匹配 +10%**
   - 关键示意：
     ```python
     ctx = (city, hour, weather, supply, demand, event)
     multipliers = {"0.8x", "1.0x", "1.2x", "1.5x", "2.0x", "2.5x"}
     chosen = ucb_select(ctx, multipliers)   # 探索-利用
     price = base_price * chosen
     ```

2. **多目标 RL（核心）**
   - 关键设计：**三目标加权**——收入 0.5 + 体验 0.3 + 司机 0.2
   - 关键能力：**多目标联合**
   - 关键数字：**满意度 +5%**

3. **Vowpal Wabbit（核心）**
   - 关键设计：**VW 实现 Bandit**——**在线学习 < 10ms**
   - 关键能力：**可扩展**
   - 关键数字：**延迟 < 10ms**

4. **自研 RL 平台（核心）**
   - 关键设计：**训练 / 部署 / A/B / 监控一体**
   - 关键能力：**千城市独立**
   - 关键数字：**覆盖 100+ 城市**

5. **实时定价（核心创新）**
   - 关键设计：**请求来了 → VW 实时出价**
   - 关键能力：**秒级响应**
   - 关键数字：**订单匹配 +10%**

### 6.5 真实落地路径（基于上述 4 个案例提炼）

**0 → 1 阶段：3-6 个月**

- 选「**Contextual Bandit**」（**最简单**）——**10+ 场景**
- 关键设计：**奖励函数必须对齐业务指标**
- 团队：**2-3 人**
- 验证标准：**探索-利用平衡**、**延迟 < 100ms**

- 扩展到「**100+ 场景**」
- 引入「**Deep RL（PPO）**」——连续动作 + 长期价值
- 引入「**Vowpal Wabbit 在线学习**」——延迟 < 10ms
- 团队：5-10 人
- 验证标准：**业务指标 +5%**

**10 → 100 阶段：12-24 个月**

- 扩展到「**千场景**」
- 引入「**多目标 RL**」——多目标加权
- 引入「**离线模拟器**」——上线前评估
- 团队：10-30 人
- 验证标准：**模拟器与线上 90%+ 吻合**、**业务指标 +10%**

**100 → 1000 阶段：12-24 个月**

- 引入「**自研 RL 平台**」——训练 / 部署 / A/B 一体
- 引入「**在线学习 + 实时对抗**」
- 团队：30-100 人
- 验证标准：**训练-部署 < 1 天**、**对抗周期 月级**

> - 4 个真实案例（电商广告 / 短视频重排 / 出行定价 / 银行反欺诈）印证：**RL 不是「**DQN**」，是「**Contextual Bandit + PPO + 多目标 + 模拟器 + 在线学习**」**5 件套**。

> - 99% 的失败来自「**探索过激 + 奖励单一 + 没有模拟器 + RL 直接上 AB**」——必须有 **保守开局 + 多目标 + 模拟器 + 灰度**。
> - 真正的 ROI 来自「**eCPM +15% / GMV +8% / 匹配 +10% / 召回 +20%**」——是**大厂核心强化学习基础设施的命脉**。
