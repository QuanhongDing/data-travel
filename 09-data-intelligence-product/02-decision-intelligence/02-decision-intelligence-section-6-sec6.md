### 2.1 蚂蚁集团"**金融决策大脑 10 亿+ 次/日**"6+ 年（2018-2024）

**背景（Why）**

蚂蚁 2018 年面临**金融决策**挑战：
- **「**花呗/借呗/保险/财富**」**——**「**全栈金融决策**」**——**「**决策大脑**」**

**触发点（What）**

2018 年**蚂蚁推出金融决策大脑**（[蚂蚁 2018]）——**目标**：「**日均 10 亿+ 决策、延迟 < 50ms、ROI +30%**」**。

**详细做法（How）**

蚂蚁决策大脑的**5 大核心组件**：

1. **「**规则引擎（Drools 自研）**」**（核心创新）
   - 关键设计：**「**规则 + ML（GBDT + DNN）**」**——**「**Flink 实时**」**——**「**因果推断（DML）**」**——**「**LLM + Agent 决策**」**
2. **「**ML 模型（GBDT + DNN）**」**（核心）
3. **「**Flink 实时计算**」**（核心）
4. **「**因果推断（DML）**」**（核心）
5. **「**LLM + Agent 决策**」**（核心创新）

**蚂蚁决策大脑关键数字**（[2018-2024 公开数据]）：

| 指标 | 改前 | 改后 | 提升 |
| --- | --- | --- | --- |
| **「**日均决策**」** | 1 亿 | 10 亿+ | **+900%** |
| **「**决策延迟**」** | 200ms | < 50ms | **-75%** |
| **「**决策 ROI**」** | 基线 | +30% | **+30%** |
| **「**金融决策**」** | 不可用 | 100% | **∞** |
| **「**决策大脑**」** | 不可用 | 100% | **∞** |

**具体数字（How much）**

- 团队规模：蚂蚁决策大脑团队 500+ 人
- 关键数字：
  - **日均 10 亿+ 决策**
  - **延迟 < 50ms**
- 业务影响：覆盖**花呗 / 借呗 / 保险 / 财富**

**失败教训**

- 早期**「**决策慢 + ROI 低**」**——倒逼**「**规则 + ML + 实时 + 因果 + LLM 决策**」**

### 2.5 真实落地路径（基于上述 4 个案例提炼）

- 扩展到**1 亿+ 决策/日**
- 引入**「**因果推断（uplift/DML）**」**（**生产**）
- 引入**「**Contextual Bandit**」**
- 团队：10-30 人

**100 → 1000 阶段：12-24 个月**

- 引入**「**LLM + Agent 决策**」**
- 引入**「**GNN 图决策**」**
- 团队：30-100 人

> **本节小结**：
> - 4 个真实案例（蚂蚁 / 阿里妈妈 / 字节 / 银行）印证：**决策智能不是「**规则引擎**」，是「**规则 + ML + 实时 + 因果 + LLM/Agent**」**5 件套。
> - 关键时间线：6+ 年 / 6+ 年 / 5+ 年 / 5+ 年 —— **决策智能是 5+ 年长期工程**。
> - 选型第一原则：**「**规则引擎**」**（**最简单**）——**10+ 决策** → **「**ML 模型 + Flink 实时**」**（**必须**）→ **「**因果推断 + Contextual Bandit**」**（**生产**）→ **「**LLM + Agent + GNN**」**（**AI 时代**）。
> - 99% 的失败来自「**决策慢 + ROI 低 + 召回低**」——必须有**规则 + ML + 实时 + 因果 + LLM**。
> - 真正的 ROI 来自「**日均 100 亿+ 决策 / ROI +30% / 召回 +30% / 延迟 -75%**」——是**大厂核心决策智能基础设施的命脉**。
