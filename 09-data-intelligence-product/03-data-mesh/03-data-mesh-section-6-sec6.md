2. **「**数据所有权**」**（核心）
3. **「**数据产品**」**（核心）
4. **「**跨域消费**」**（核心）

| **「**跨域消费效率**」** | 基线 | +10x | **+10x** |

> **本节小结**：
> - 4 个真实案例（ING / Shopify / Netflix / 阿里云）印证：**Data Mesh 不是「**数据集中化**」，是「**业务能力 + 数据所有权 + 数据产品 + 跨域消费 + 元数据**」**5 件套。
> - 关键时间线：5+ 年 / 5+ 年 / 5+ 年 / 5+ 年 —— **Data Mesh 是 5+ 年长期工程**。
> - 选型第一原则：**「**业务能力划分**」**（**最简单**）——**5-10 数据域** → **「**数据所有权 + 数据产品**」**（**必须**）→ **「**跨域消费 + 元数据**」**（**生产**）→ **「**联邦查询 + Iceberg**」**（**AI 时代**）。
> - 99% 的失败来自「**数据集中化失败 + 跨域消费慢 + 数据所有权弱**」——必须有**业务能力 + 数据所有权 + 数据产品 + 跨域消费**。
> - 真正的 ROI 来自「**跨域效率 5-10x + AI 数据 1 周 + EB 级数据湖**」——是**大厂核心数据组织基础设施的命脉**。
