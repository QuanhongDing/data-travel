# Ch9 · 数据智能产品

> **一句话定位**：让 AI 不只在后台——变成业务可消费的产品：智能标签 / 智能 BI / 精细化运营 / 预测决策。

## 画像映射

本章对应 **R5 数据智能类产品认知**（招聘要求第 5 条）：

- 智能标签（事实标签 / 模型标签 / 预测标签）
- 智能 BI（自然语言查询 NL2SQL / 自动洞察）
- 精细化运营（人群运营 / 触达策略）
- 预测决策（推荐 / 营销 / 风控）

> P7 会"做模型"，P8 会"做平台"，**资深架构师会"做产品"**——让 AI 能力从"内部工具"变成"业务可消费的产品"。

## 本章要回答的核心问题

1. **智能标签体系怎么设计？** 事实标签（基础属性）/ 模型标签（行为偏好）/ 预测标签（流失概率）——三类标签的工程化链路？
2. **标签平台怎么搭建？** 实时标签（流式计算）vs 离线标签（批处理）——如何平衡实时性与计算成本？
3. **智能 BI 怎么实现 NL2SQL？** Text2SQL / Text2Metrics / 自动洞察——从自然语言到可执行查询的全链路？
4. **精细化运营怎么设计？** 人群圈选、触达策略、A/B 实验、效果归因——如何用数据驱动业务决策？
5. **预测决策系统怎么搭建？** 规则引擎 vs ML 模型 vs LLM Agent——不同决策场景的技术选型？
6. **数据中台与数据网格（Data Mesh）怎么选？** 中心化 vs 联邦化——大型组织的"数据组织"难题？
7. **AI 计算平台怎么设计？** 训练平台 / 推理平台 / 模型市场——把 AI 能力产品化？

## 画像能力小结

完成本章后，你应当能够：

- 设计智能标签体系（事实 / 模型 / 预测三类），并搭建标签平台
- 选型实时 vs 离线标签的工程方案（Flink / Spark / 向量库）
- 实现 NL2SQL / Text2Metrics，把自然语言转化为可执行查询
- 设计精细化运营系统（人群圈选 / 触达策略 / 效果归因）
- 搭建预测决策系统（规则引擎 / ML / LLM Agent），并与业务系统集成
- 评估数据中台 vs 数据网格的取舍，给出组织级数据架构建议
- 搭建 AI 计算平台（训练 / 推理 / 模型市场），让 AI 能力产品化
- **把模糊业务问题转化为可量化指标**——这是数据智能产品的核心能力
