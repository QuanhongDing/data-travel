### 6.1 阿里瓴羊 QuickBI 智能助手 4+ 年演进（2020-2024）

**背景（Why）**

阿里 2020 年面临**业务自助分析**挑战：
- **5000+ 指标**——**传统 BI**——**「**查数难**」**
- **100+ 业务域**——**业务方**——**「**不会写 SQL**」**
- **运营**——**「**人人都要会看数**」**——**传统 BI 不够**

**触发点（What）**

2020 年**阿里启动瓴羊 QuickBI 智能助手**（[阿里云栖 2023]）——**目标**：「**人人能查数**」。

**详细做法（How）**

阿里 QuickBI 智能助手的**6 大核心创新**：

1. **指标语义层（OneMetric 平台）**
   - 关键设计：**所有指标**——**统一管理**——**「**指标 = 名称 + 定义 + 计算公式 + 维度 + Owner**」**
   - 关键代码：
     ```python
     # 阿里 OneMetric 指标定义
     class Metric:
         name: str  # "GMV"
         display_name: str  # "成交总额"
         definition: str  # "订单创建 - 退款"
         formula: str  # "SUM(amount) WHERE status='paid'"
         dimensions: List[str]  # ["city", "dt", "category"]
         owner: str  # "@user-1234"
     # 业务方自助查"上海昨天的 GMV"
     # → 自动生成 SQL
     # → 自动路由到 MaxCompute
     ```

2. **Text2SQL（核心创新）**
   - 关键设计：**Qwen2.5-Coder 微调**——**中文 NL2SQL**——**业内最强**
   - 关键能力：**「**自然语言**」**——**「**SQL**」**——**准确率 95%+**
   - 关键代码：
     ```python
     # 阿里 Text2SQL 流程
     def nl2sql(query, schema):
         # 1. 解析 schema
         schema_text = format_schema(schema)
         # 2. 调用 LLM
         prompt = f"你是一个 SQL 专家。Schema: {schema_text}\n问题: {query}\n请写 SQL:"
         sql = qwen_coder.generate(prompt)
         # 3. 校验
         validated = sql_validator.check(sql)
         return sql
     ```

3. **MaxCompute 沙箱（关键）**
   - 关键设计：**MaxCompute 隔离环境**——**安全执行 SQL**
   - 关键能力：**业务方自助查数**——**不会影响生产**

4. **多轮精修（ReAct + Reflexion）**
   - 关键设计：**多轮对话**——**ReAct**——**「**思考 + 行动**」**
   - 关键代码：
     ```python
     # 阿里多轮精修
     class QuickBIAgent:
         def answer(self, user_query, history):
             # 1. 意图理解
             intent = self.understand_intent(user_query, history)
             # 2. SQL 生成
             sql = self.text2sql(intent, self.schema)
             # 3. 沙箱执行
             result = self.maxcompute.execute(sql)
             # 4. 精修（如果结果不对）
             if not result.is_relevant:
                 sql = self.refine(sql, user_query, result)
                 result = self.maxcompute.execute(sql)
             return result
     ```

5. **工具集成（核心能力）**
   - **可视化**——**自动生成图表**——**「**柱状图 / 折线图 / 饼图**」**
   - **归因分析**——**自动定位根因**——**「**为什么跌了**」**
   - **Python 沙箱**——**高级计算**——**「**同期群分析**」**

6. **MCP 协议（2024+）**
   - 关键设计：**Anthropic MCP**——**标准化**——**「**一次开发**」**「**多端使用**」**

**阿里 QuickBI 智能助手关键数字**（[阿里 2023-2024 公开数据]）：

| 指标 | 改前 | 改后 | 提升 |
| --- | --- | --- | --- |
| **日活用户** | 1000 | 10 万+ | **100 倍** |
| **日均查询** | 5 万 | 500 万+ | **100 倍** |
| **准确率** | 60% | 85%+ | **25% 提升** |

**具体数字（How much）**

- 团队规模：阿里瓴羊团队 200+ 人
- 关键数字（[2024 公开数据]）：
  - **10 万+ 日活用户**
