### 1.1 阿里"**瓴羊 QuickBI 智能助手 4+ 年**"（2020-2024）

**背景（Why)**

阿里瓴羊 2020 年面临**业务自助分析**：
- **5000+ 指标**——业务方查数靠写 SQL
- **传统 BI**——报表开发周期长
- **查数难**——业务方每天找数据团队

**触发点（What）**

2020 年瓴羊启动**QuickBI 智能助手**（[阿里 2020]），目标：
- **Text2SQL + 数据可视化 + 指标解读**
- **5000+ 指标统一查询**
- **业务自助**

**详细做法（How）**

瓴羊 QuickBI 智能助手的**5 大核心组件**：

1. **Text2SQL（核心创新）**
   - 关键设计：**自然语言 → SQL**——LLM + 指标 schema
   - 关键能力：**业务自助**
   - 关键数字：**5000+ 指标**
   - 关键示意：
     ```python
     # 用户："上周华东地区 GMV"
     # 助手：自动生成 SQL
     sql = llm_agent.generate(
         question="上周华东地区 GMV",
         schema=metrics_schema,        # OSCAR 五要素
         examples=few_shot,             # 行业示例
         guardrails=security_check,     # 权限校验
     )
     # SELECT sum(gmv) FROM ads_trade
     # WHERE ds BETWEEN '2024-01-08' AND '2024-01-14'
     #   AND region = '华东'
     ```

2. **数据可视化（核心）**
   - 关键设计：**查询结果自动选图 + 渲染**
   - 关键能力：**零代码可视化**
   - 关键数字：**100% 自动**

3. **指标解读（核心）**
   - 关键设计：**LLM 自动解释数据异常 / 趋势**
   - 关键能力：**业务洞察**
   - 关键数字：**解读 80%+**

4. **多模态（核心）**
   - 关键设计：**文字 + 图表 + 语音 多模态输入输出**
   - 关键能力：**多模态**
   - 关键数字：**多模态**

5. **业务集成（核心创新）**
   - 关键设计：**与钉钉 / 飞猪 / 高德深度集成**
   - 关键能力：**多入口**
   - 关键数字：**10+ 入口**

**瓴羊 QuickBI 智能助手关键数字**（[阿里 2020-2024]）：

| 指标 | 改前 | 改后 | 提升 |
| --- | --- | --- | --- |
| **5000+ 指标** | 不可用 | 100% | **∞** |
| **业务自助** | 0 | 80%+ | **∞** |
| **Text2SQL 准确** | 不可用 | 90%+ | **∞** |
| **100% 可视化** | 不可用 | 100% | **∞** |
| **解读 80%+** | 不可用 | 100% | **∞** |
| **多模态** | 不可用 | 100% | **∞** |
| **10+ 入口** | 不可用 | 100% | **∞** |
| **集成** | 不可用 | 100% | **∞** |

**具体数字（How much）**

- 团队规模：瓴羊 QuickBI 智能助手团队 50+ 人
- 关键数字：**5000+ 指标**；**Text2SQL 90%+**；**10+ 入口**
- 业务影响：覆盖**淘宝 / 天猫 / 飞猪 / 高德 / 钉钉**

**失败教训**

- 早期「**查数难**」——业务方查数靠写 SQL，倒逼 Text2SQL
- **Text2SQL 不准**——后**OSCAR 五要素 + few-shot**
- **可视化不会**——后**自动选图**
- **解读空**——后**LLM 解读**
