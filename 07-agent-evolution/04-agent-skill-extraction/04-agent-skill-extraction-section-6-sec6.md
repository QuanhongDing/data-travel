### 6.1 Cursor Composer「**IDE 多文件编辑**」1+ 年（2023-2024）

**背景（Why）**

Cursor 2023 年面临**IDE 自动化**挑战：
- **GitHub Copilot**——**只补全**——**「**不智能**」**
- **Cursor**——**「**多文件编辑 + 上下文**」**——**「**Skill 提取**」**

**触发点（What）**

2023 年**Cursor 启动 Composer 项目**（[Cursor 博客 2024]）——**目标**：「**从用户行为提取 Skill**」。

**详细做法（How）**

Cursor Composer 的**5 大核心组件**：

1. **用户行为日志（核心）**
   - 关键设计：**用户接受 / 拒绝 / 修改**——**全记录**
   - 关键代码：
     ```python
     # Cursor 行为日志
     class ComposerLog:
         def log(self, user_id, action):
             self.events.append({
                 "user_id": user_id,
                 "action": action,  # accept / reject / edit
                 "context": self.get_context(),
                 "diff": self.get_diff(),
                 "timestamp": now()
             })
     # 提取 Skill
     def extract_skill(self, log):
         # 1. 聚类相似行为
         patterns = cluster(log, threshold=0.8)
         # 2. 提取为 Skill
         for pattern in patterns:
             skill = Skill(
                 name=pattern.name,
                 trigger=pattern.trigger,
                 action=pattern.action
             )
             self.skill_lib.add(skill)
     ```

2. **Skill 库（核心）**
   - 关键设计：**Skill 库**——**「**可复用**」**——**可检索**
   - 关键能力：**「**库**」**——**「**「**多文件**」**」**

3. **触发匹配（核心）**
   - 关键设计：**用户输入**——**「**自动触发 Skill**」**
   - 关键能力：**「**「**自动化**」**」

4. **多文件编辑（核心）**
   - 关键设计：**Skill**——**「**多文件**」**——**「**原子性**」**
   - 关键能力：**「**「**Composer**」**

5. **持续学习（核心）**
   - 关键设计：**每日训练**——**Skill 库**——**「**持续更新**」**

**Cursor Composer 关键数字**（[Cursor 2024]）：

| 指标 | 改前 | 改后 | 提升 |
| --- | --- | --- | --- |
| **代码接受率** | 15% | 30% | **2 倍** |
| **多文件编辑** | 不可用 | 80%+ | **∞** |
| **Skill 库** | 0 | 1000+ | **∞** |
| **日活** | 0 | 100 万+ | **∞** |
| **「**ARR**」** | 0 | 1 亿+ | **∞** |

**具体数字（How much）**

- 团队规模：Cursor Composer 团队 50+ 人
- 关键数字（[2024 公开数据]）：
  - **30% 接受率**
  - **1000+ Skill**
  - **1 亿+ ARR**
- 业务影响：覆盖**全球 100+ 国家**

**失败教训**

- 早期**Skill 难提取**——倒逼**「**聚类算法**」**

> **本节小结**：
> - 4 个真实案例（Cursor / Devin / Anthropic / 阿里）印证：**Agent Skill 提取不是「**写 Skill**」，是「**用户行为日志 + 聚类算法 + Skill 库**」**组合。
> - 关键时间线：Cursor 1+ 年 / Devin 1+ 年 / Anthropic 1+ 年 / 阿里 1+ 年 —— **Agent Skill 是 2023 后的核心战场**。
> - 选型第一原则：**用户行为日志**（**最简单**）——**聚类 PoC** → **Skill 库**（**必须**）→ **持续学习**（**每日更新**）→ **MCP 协议**（**AI 时代**）。
> - 99% 的失败来自「**Skill 难提取 + 库难建**」——必须有**聚类 + 检索 + 持续学习**。
> - 真正的 ROI 来自「**接受率 2 倍 + 14% 全自动率 + 1 亿 ARR**」——是**AI 时代 Agent 智能化的核心**。
