### 6.1 DeepSeek-R1「**GRPO 推理突破**」1+ 年（2024-2025）

**背景（Why）**

DeepSeek 2024 年面临**推理 SOTA**挑战：
- **OpenAI o1**（**2024-09**）——**推理 SOTA**——**RLHF 范式**
- **传统 SFT + RLHF**——**数学 / 代码推理**——**受限于「**单步奖励**」**
- **DeepSeek-R1**——**「**GRPO**」**——**推理突破**

**触发点（What）**

2024 年**DeepSeek 启动 R1 项目**（[DeepSeek 论文 2025-01]）——**目标**：「**开源推理 SOTA**」。

**详细做法（How）**

DeepSeek-R1 的**5 大核心创新**：

1. **GRPO（核心创新，Group Relative Policy Optimization）**
   - 关键设计：**组内相对优势**——**无需 Critic 模型**——**「**同一 prompt 多个回答**」**——**「**相对评分**」**
   - 关键代码：
     ```python
     # GRPO 简化版
     for prompt in prompts:
         # 1. 采样 K 个回答
         responses = [generate(prompt) for _ in range(K)]
         # 2. 计算每个回答的奖励
         rewards = [reward(r) for r in responses]
         # 3. 计算组内相对优势
         advantages = [(r - mean(rewards)) / std(rewards) for r in rewards]
         # 4. 用相对优势更新策略
         loss = -compute_policy_loss(responses, advantages)
         optimize(loss)
     ```

2. **零 Critic（核心优势）**
   - 关键设计：**不需要 Critic 模型**——**省 50% 训练资源**
   - 关键能力：**「**简单 + 强**」**——**SOTA 数学 / 代码**

3. **规则化奖励（关键）**
   - 关键设计：**数学**——**答案正确** + **格式正确**
   - 关键能力：**「**规则化**」**——**无需奖励模型**

4. **冷启动（关键技巧）**
   - 关键设计：**先 SFT 冷启动**——**再用 GRPO**
   - 关键能力：**稳定训练**——**「**起点好**」**

5. **蒸馏到小模型（关键）**
   - 关键设计：**R1 671B**——**蒸馏到 1.5B / 7B / 14B / 32B / 70B**
   - 关键能力：**小模型也具备推理能力**——**开源**

### 6.2 OpenAI「**RLHF 起源**」5+ 年（2017-2022）

**背景（Why）**

OpenAI 2017 年面临**RLHF 起源**挑战：
- **GPT-2 / GPT-3**——**纯 SFT**——**「**不听话**」**
- **InstructGPT**——**RLHF**——**「**奠基论文**」**

**触发点（What）**

2017 年**OpenAI 启动 InstructGPT 项目**（[OpenAI 论文 2022-03]）——**目标**：「**让 LLM 听话**」。

**详细做法（How）**

OpenAI RLHF 的**5 大核心组件**：

1. **Reward Model（核心）**
   - 关键设计：**人类标注**——**训练**——**「**好回答**」**得分高
   - 关键代码：
     ```python
     # RLHF 简化版
     # 1. 人类标注「(prompt, response_a, response_b, 偏好)」
     # 2. 训练 Reward Model
     for batch in human_labeled_data:
         # r_a = reward_model(prompt, response_a)
         # r_b = reward_model(prompt, response_b)
         # loss = -log(sigmoid(r_a - r_b))  # A > B
         optimize(loss)
     ```

2. **PPO（核心）**
   - 关键设计：**Proximal Policy Optimization**——**「**稳定更新**」**
   - 关键能力：**「**稳定 RLHF**」**

3. **3 阶段训练（核心）**
   - **阶段 1**：**SFT**（**人类标注示范**）
   - **阶段 2**：**Reward Model**（**人类排序**）
   - **阶段 3**：**PPO**（**RM 反馈**）

4. **InstructGPT 数据集（核心）**
   - 关键设计：**数万人工标注**——**33k prompts**
   - 关键能力：**「**RLHF 起源**」**

5. **ChatGPT 应用（核心）**
   - 关键设计：**RLHF + 大量 RLHF 数据**——**ChatGPT 2022-11 发布**
   - 关键能力：**「**对话式 AI**」**——**全球爆火**

### 6.3 字节跳动"**豆包 RLHF**"3+ 年（2021-2024）

**详细做法（How）**

1. **大规模中文标注（核心）**
   - 关键设计：**100 万+ 中文 prompts**——**人类标注**
   - 关键代码：
     ```python
     # 字节 RLHF 简化版
     # 1. 人类标注 100 万+ 中文 prompt
     # 2. 训练中文 Reward Model
     for batch in chinese_reward_data:
     ```

**触发点（What）**

2023 年**Cursor 启动 Accept/Reject 训练**（[Cursor 博客 2024]）——**目标**：「**让 Copilot 越用越聪明**」。

**详细做法（How）**

Cursor Accept/Reject 训练的**5 大创新**：

1. **Accept/Reject 信号（核心）**
   - 关键设计：**用户**——**「**接受 / 拒绝**」**——**直接训练**
   - 关键代码：
     ```python
     # Cursor 训练数据收集
     for interaction in user_sessions:
         # 1. 用户接受 / 拒绝
         if interaction.accepted:
             # 2. 存为正样本
             positive_samples.append(interaction)
         else:
             # 3. 存为负样本
             negative_samples.append(interaction)
     # 4. 训练
     loss = contrastive(positive_samples, negative_samples)
     optimize(loss)
     ```

2. **代码接受率（核心）**
   - 关键设计：**30% 接受率**——**持续训练**
   - 关键能力：**30% 接受率**——**GitHub Copilot 2 倍**

3. **多任务学习**
4. **在线学习（核心）**

   - 关键能力：**「**实时优化**」**

5. **持续 A/B 测试**
