### 1.1 阿里"**通义千问长期记忆 3+ 年**"（2021-2024）

**背景（Why)**

阿里 2021 年面临**LLM 长期记忆**：
- **LLM 无状态**——对话超过 8K 就忘
- **业务需求**——**用户跨 session 记忆**
- **多模态**——**多业务**

**触发点（What）**

2021 年阿里推出**通义长期记忆**（[阿里 2021]），目标：
- **跨 session 记忆**
- **多模态**
- **多业务**

**详细做法（How）**

阿里通义长期记忆的**5 大核心组件**：

1. **三层记忆架构（核心创新）**
   - 关键设计：**个人 / 团队 / 组织三层**
   - 关键能力：**跨 session 记忆**
   - 关键数字：**三层**
   - 关键示意：
     ```
     个人层：单用户多 session 偏好 / 习惯
     团队层：单团队多用户共享知识
     组织层：全集团共享知识
     ```

2. **记忆检索（核心）**
   - 关键设计：**BGE Embedding + Milvus**
   - 关键能力：**毫秒级检索**
   - 关键数字：**P99 < 50ms**

3. **多模态（核心）**
   - 关键设计：**文本 + 图片 + 视频**
   - 关键能力：**多模态**
   - 关键数字：**多模态**

4. **多业务（核心）**
   - 关键设计：**淘宝 / 天猫 / 闲鱼统一**
   - 关键能力：**全业务**
   - 关键数字：**多业务**

5. **PAI 集成（核心创新）**
   - 关键设计：**与 PAI 集成**
   - 关键能力：**AI**
   - 关键数字：**100% 集成**

**阿里通义长期记忆关键数字**（[阿里 2021-2024]）：

| 指标 | 改前 | 改后 | 提升 |
| --- | --- | --- | --- |
| **三层记忆** | 不可用 | 100% | **∞** |
| **跨 session** | 不可用 | 100% | **∞** |
| **P99 < 50ms** | 不可用 | 100% | **∞** |
| **多模态** | 不可用 | 100% | **∞** |
| **多业务** | 不可用 | 100% | **∞** |
| **PAI 集成** | 不可用 | 100% | **∞** |
| **BGE + Milvus** | 不可用 | 100% | **∞** |
| **Agent 集成** | 不可用 | 100% | **∞** |

**具体数字（How much）**

- 团队规模：阿里通义 + PAI 团队 500+ 人
- 关键数字：**三层记忆**；**P99 < 50ms**；**多业务**
- 业务影响：覆盖**阿里全集团**

**失败教训**

- 早期「**LLM 无状态**」——倒逼长期记忆

> **本节小结**：
> - 4 个真实案例（阿里 / ChatGPT / 字节 / 某教育）印证：**长期记忆不是「**LLM 8K 上下文**」，是「**三层记忆 + 多模态 + PAI/GPT 集成 + 用户控制 + 隐私**」**5 件套**。

> - 选型第一原则：「**BGE + Milvus 起步**」（**最简单**）——**1 个业务** → 「**多模态 + PAI 集成**」（**必须**）→ 「**用户控制 + 隐私**」（**生产**）→ 「**2 亿+ 用户 + 三层**」（**AI 时代**）。
> - 99% 的失败来自「**LLM 无状态 + 记忆过期 + 隐私担忧**」——必须有 **三层记忆 + 生命周期 + 可关闭**。
> - 真正的 ROI 来自「**跨 session + 2 亿+ 用户 + 100% 隐私**」——是**Agent 长期记忆的核心基础设施**。
