### 6.1 字节跳动"**扣子 Coze**"4+ 年（2020-2024）

**背景（Why）**

字节 2020 年面临**Agent 资产化**挑战：
- **内部**——**100+ 业务线**——**「**重复造 Agent**」**
- **外部**——**「**无统一 Agent 平台**」**——**「**零代码 / 资产化**」**

**触发点（What）**

2020 年**字节启动扣子 Coze 项目**（[字节技术博客 2024]）——**目标**：「**零代码 + 资产化 + 生态**」。

**详细做法（How）**

字节扣子 Coze 的**5 大核心组件**：

1. **零代码 Agent 构建（核心）**
   - 关键设计：**拖拽式**——**业务用户**——**5 分钟构建 Agent**
   - 关键能力：**降门槛**——**从程序员到业务**
   - 关键代码：
     ```yaml
     # 扣子 Coze Agent 定义
     name: customer_service_agent
     description: 抖音电商客服助手
     nodes:
       - type: llm
         model: doubao-pro
         prompt: |
           你是抖音电商客服。
           用户问题：{{user_query}}
           上下文：{{retrieved_docs}}
       - type: knowledge_base
         kb_id: kb_123
         query: {{user_query}}
         top_k: 5
       - type: tool
         tool_name: query_order
     ```

2. **资产化发布（核心创新）**
   - 关键设计：**发布到多端**——**豆包 / 飞书 / 抖音**
   - 关键能力：**一次开发**——**多端运行**
   - 关键代码：
     ```python
     # 扣子资产化发布
     class CozeAgent:
         def publish(self, agent_id, channels):
             # channels: ['doubao', 'feishu', 'douyin']
             for ch in channels:
                 self.publish_to_channel(agent_id, ch)
     ```

3. **模板市场（Bot Store，核心）**
   - 关键设计：**社区贡献**——**100+ 模板**
   - 关键能力：**复用 + 定制**

4. **插件市场（核心）**
   - 关键设计：**1000+ 插件**——**业务方开发**——**共享**
   - 关键能力：**生态**——**平台效应**

5. **多 Agent 协作（核心）**
   - 关键设计：**多 Agent**——**「**Workflow**」**——**协作**
   - 关键能力：**复杂流程**

**字节扣子 Coze 关键数字**（[字节 2024]）：

| 指标 | 改前 | 改后 | 提升 |
| --- | --- | --- | --- |
| **Agent 数** | 100（内部） | 1 亿+ | **100 万倍** |
| **用户数** | 1000 | 1 亿+ | **100 万倍** |
| **插件数** | 0 | 1000+ | **∞** |
| **API 调用/月** | 0 | 100 亿+ | **∞** |
| **覆盖国家** | 0 | 100+ | **∞** |

**具体数字（How much）**

- 团队规模：字节扣子 Coze 团队 200+ 人
- 关键数字（[2024 公开数据]）：
  - **1 亿+ 用户**
  - **1000+ 插件**
  - **100 亿+ API 调用/月**
- 业务影响：覆盖**全球 100+ 国家**——**Agent 平台全球第一梯队**

**失败教训**

- 早期**零代码弱**——倒逼**「**拖拽**」**
- **「**资产化**」**——倒逼**「**多端发布**」**
- **「**生态**」**——倒逼**「**插件市场**」**

### 6.5 真实落地路径（基于上述 4 个案例提炼）

**0 → 1 阶段：3-6 个月**

- 选**Coze / Dify / 阿里百炼**（**最简单**）——**零代码 Agent 平台**
- 接入**1 个业务场景**（**客服 / 助手**）
- 团队：2-3 人

**1 → 10 阶段：6-12 个月**

- 扩展到**10+ 业务**
- 引入**模板市场**（**复用 + 定制**）
- 引入**插件生态**
- 团队：5-10 人

**10 → 100 阶段：12-24 个月**

- 扩展到**100+ Agent**
- 引入**MCP 协议**（**Anthropic**）
- 引入**多 Agent 协作**
- 团队：10-30 人

**100 → 1000 阶段：12-24 个月**

- 引入**AI 优化**——**自动生成 Agent**
- 引入**「**资产市场**」**——**生态**
- 团队：30-100 人

> **本节小结**：
> - 4 个真实案例（字节 / 阿里 / OpenAI / Salesforce）印证：**Agent 资产管理不是「**写一个 Agent**」，是「**零代码 + 模板市场 + 插件生态 + 多端发布**」**组合。
> - 关键时间线：字节 4+ 年 / 阿里 3+ 年 / OpenAI 1+ 年 / Salesforce 1+ 年 —— **Agent 资产管理是 2023 后的核心战场**。
> - 选型第一原则：**Coze / Dify / 阿里百炼**（**最简单**）——**零代码 PoC** → **模板市场 + 插件生态**（**必须**）→ **多 Agent 协作 + MCP**（**AI 时代**）。
> - 99% 的失败来自「**零代码弱 + 资产化弱 + 生态弱**」——必须有**拖拽 + 多端发布 + 插件市场**。
> - 真正的 ROI 来自「**300 万 GPT + 1 亿用户 + 1 亿 ARR**」——是**AI 时代 Agent 落地的核心生态**。
