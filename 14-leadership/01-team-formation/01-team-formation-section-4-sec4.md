## 4. 工程实现

### 4.1 落地步骤

**Step 1：搭建人才画像（3-5 天）**

1. 召集岗位负责人、HRBP、资深面试官 3-5 人。
2. 用「**6 个月关键产出**」反推能力。
3. 拆解 4-6 个能力维度，每个维度写 BAR 锚点。
4. 权重分配，总和 100%。
5. 输出《人才画像文档》（含示例简历）。

**Step 2：建立题库（5-10 天）**

1. 每个能力维度 2-3 道题（共 10-15 题）。
2. 每道题基于 **STAR 行为事件**，避免「你会怎么做」式空话。
3. 每道题配 BAR 锚点（1-5 分的行为描述）。
4. 题库版本化管理（Git 仓库 + Reviewer 评审）。

**Step 3：培养面试官（持续）**

1. 招募「**潜在面试官**」（通常是 P7+ 资深工程师）。
2. 4 阶段培养：影子 → 副 → 独立 → 校准。
3. 每季度 1 次「**打分校准会**」，对齐 BAR 标准。
4. 设立「**金牌面试官**」荣誉 + 晋升加分。

**Step 4：搭建漏斗看板（1-2 周）**

1. 工具：飞书招聘 / Moka / 北森 / Greenhouse。
2. 关键指标：投递率 / 面试率 / Offer 率 / Accept 率 / 试用期通过率 / 1 年留存率。
3. 周会 Review 漏斗，发现卡点。

**Step 5：雇主品牌运营（持续）**

1. 技术博客（Medium / 知乎 / 掘金 / 公司官网）。
2. 开源项目（GitHub Star 累计目标）。
3. 技术大会（QCon / ArchSummit / KubeCon 演讲）。
4. 内推奖励（内推成功 = 1-3 个月薪资）。

### 4.2 关键技术点

**1. BAR 锚点撰写**

- 每分对应 1 个**具体行为**，避免「强 / 中 / 弱」。
- 参考模板：

```markdown
# 系统设计维度 BAR 锚点

## 1 分
- 候选人能描述系统的 1-2 个模块功能
- 无法解释模块间依赖关系
- 没有 trade-off 意识

## 3 分
- 能拆解 3-5 个核心组件
- 能说清关键 trade-off（如缓存 vs 一致性）
- 无法给出量化指标

## 5 分
- 能拆解 10+ 组件，含上下游依赖
- 明确说出 trade-off + 备选方案
- 量化性能指标（如 QPS、Latency）
- 考虑过 SLO / 容灾 / 成本
```

**2. 多面试官交叉（Panel Interview）**

- 3-5 个面试官独立打分，避免「**主面试官一句话定生死**」。
- 合议规则：
  - **强反对**（1 个面试官打 1 分）→ 必须深度讨论。
  - **中位数为通过线** → 通过。
  - **分数方差 > 2** → 校准会讨论。

**3. 防偏见机制**

- **结构化打分卡**：面试官只能在 1-5 分中选，不能写主观评语作为主要依据。
- **延迟评价**：面试中不做最终判断，先看 30 分钟再打分。
- **多面试官盲评**：面试官之间不交流，独立打分，最后汇总。
- **校准会**：每季度跨团队校准，对齐标准。

**4. 试用期跟踪（Probation Tracking）**

- 入职 1 周：Onboarding Buddy 1:1（技术环境、团队、业务）。
- 入职 2 周：1:1（适应情况、卡点）。
- 入职 1 个月：1:1（关键产出对齐、初步反馈）。
- 入职 2 个月：1:1（中期 Review + 早期干预）。
- 入职 3 个月：试用期答辩（5 人评委会打分）。
- 通过率 < 80% 的团队 → 招聘漏斗需优化。

### 4.3 工具链与平台（含 2024-2025 新工具）

**ATS（Applicant Tracking System）**：

- **国际**：Greenhouse、Lever、Workable、SmartRecruiters。
- **国内**：Moka、北森、e成科技、飞书招聘。

**简历解析与匹配**：

- **传统**：关键词匹配（漏斗 70% 错杀）。
- **AI 时代**：LLM 解析 + 语义匹配（漏斗 30% 错杀）。
- **2024 新工具**：Resume Worded、SkillSyncer、LoopCV。

**视频面试平台**：

- **传统**：Zoom、腾讯会议。
- **AI 增强**：HireVue（视频分析）、Micro1（AI 面试官）。

**Take-Home 评估**：

- **Coding 评估**：Codility、HackerRank、LeetCode。
- **AI 时代**：Cursor / Devin 评估候选人 Coding 风格、Commit 粒度、测试覆盖。
- **反 AI 作业**：CoderPad（实时 Coding）、屏幕共享 + 录像。

**雇主品牌平台**：

- **技术博客**：Medium、知乎、掘金、公司官网。
- **开源**：GitHub、GitLab、Sourcegraph。
- **技术大会**：QCon、ArchSummit、KubeCon、PyCon、ArchSummit。

**AI 时代工具（2024-2025）**：

- **Resume Screening Agent**：GPT-4 / Claude 自动解析简历，匹配人才画像。
- **AI Interviewer**：Candidates AI、Micro1 用 LLM 模拟面试。
- **Skills Graph**：Eightfold、Gloat 用技能图谱替代 JD。
- **Take-Home Reviewer**：自动评估代码风格、复杂度、测试覆盖。
- **AI 简历反作弊**：检测 ChatGPT 生成的 JD / 简历 / 作业。

### 4.4 代码 / 示例

**示例 1：人才画像模板（Markdown）**

```markdown
# 岗位画像：资深数据架构师（P8）

## 6 个月关键产出
- 完成公司数据湖仓一体的 0→1 架构升级
- 主导 1 个跨 BU 数据治理项目
- 培养 2 名 P7 数据架构师

## 能力维度与权重
| 维度 | 权重 | 关键考察点 |
| --- | --- | --- |
| 技术深度（图谱/RAG/Agent） | 30% | 知识图谱 / 向量库 / LLM 微调 |
| 系统设计 | 30% | 跨 BU 架构、TB 级数据、高可用 |
| 工程素养 | 15% | 代码评审、可观测、混沌工程 |
| 业务理解 | 10% | 数据资产化、业务指标体系 |
| 协作 / 影响力 | 10% | 跨团队、跨 BU 推动能力 |
| 文化匹配 | 5% | Ownership、Customer Focus、Excellence |

## BAR 锚点（节选）
### 技术深度 5 分
- 主导过 1 个 KG / RAG 项目
- 理解 Embedding / Vector Search / GNN 原理
- 能讲清 LLM 微调（LoRA / RLHF）的适用场景

### 系统设计 5 分
- 拆解 10+ 组件，含上下游依赖
- 明确 trade-off + 备选方案
- 量化性能指标（QPS / Latency / 成本）
- 考虑过 SLO / 容灾 / 多活
```
