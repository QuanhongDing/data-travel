### 7.2 决策树

```
你的目标？
├── 内部分享 → 内部分享 + 读书会
├── 团队品牌 → 金字塔 + Conference + 开源
├── 个人品牌 → Conference + 博客 + 视频
├── 行业影响力 → 开源 + Conference
└── 业务翻译 → 内部分享 + Newsletter

你的资源？
├── 时间紧 → AI 辅助布道
├── 资源足 → 多模式组合
└── 个人驱动 → 个人 IP（博客 + Conference）
```

### 7.3 组合使用

- **金字塔 + AI**：底层博客用 AI 辅助、中层演讲人工、顶层开源。
- **博客 + Conference**：博客沉淀、Conference 演讲升华。
- **开源 + 视频**：开源项目 + YouTube 教程视频。
- **Newsletter + Podcast**：双渠道触达。
