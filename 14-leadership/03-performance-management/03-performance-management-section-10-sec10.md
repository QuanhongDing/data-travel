## 10. 激励兑现

评级、薪酬包与奖金池都定完之后，还剩一次谈话：把结论当面交给员工，并把这一期没兑现的承诺解释掉。这次谈话不产生新判断，只传递已经做出的判断，所以看起来最省事，实际却最容易把前四步攒下的信用一次花光。原因是一条不对称：**人对兑现的判断基准不是「拿到了多少」，而是「承诺时听到的是什么」**——同一个数字，先说结论再说依据，和先铺垫再说结论，留下的东西完全不同（顺序为什么重要见 [§4 工程实现](03-performance-management-section-4-sec4.md) Step 4）。在这套体系里，兑现信用被归为**唯一一项「一次破裂不可逆」的资产**，处理方式只有两条：到期必兑现，或当面说明为什么变（[§4 工程实现](03-performance-management-section-4-sec4.md) 历史资产分类表）；机制上一次不兑现，会让后续所有激励的折扣率上升且不再可逆（[§3.2.7](03-performance-management-section-3-sec3.md)）。

### 10.1 什么场合用

**触发条件**（三条全成立才谈；缺一条就说明还没到兑现的时候）：

- 本期评级、薪酬包与奖金池**已经定完并走完审批**——没定完就谈，谈出来的任何数字都是一次新的承诺
- 兑现台账上本期到期的承诺条目**已经逐条对过账**（已兑现 / 已书面说明 / 待定，三种状态都有归属）
- 上一次面谈**已经给过结论**——结论与兑现顺序颠倒，员工会把结果解释成分配不公，而不是一次被解释过的判断

**谁在场**：主管与员工 1:1。涉及晋升的场合，答辩结论由评委或跨级主管事先给出，这次谈话只传递结论与依据，不在现场重新表决。

**时间窗**：这次谈话应当发生在**结论定完之后、数字到账之前（或同一天）**。数字先到账、谈话排在几天之后，是最常见的顺序反转——员工在等待期里已经跟同事对过账，你后面说的每一条依据，都被当成事后解释。

**不适用**（两种，各自走别的路径）：

- 本期结论是不达标——那时要兑现的是另一份文件（PIP），其判据、周期、资源与申诉路径都得在开始前写死（处置链见 §3.2.6，IDP 与 PIP 的区分见 [§9 改进计划（IDP）](03-performance-management-section-9-sec9.md)）
- 只有口头承诺、台账上查不到条目——先补台账再谈，否则这场谈话会滑成「我记得你说过」的比记忆，而比记忆永远是员工赢

本期交出去的东西通常长这样（数值为示例填法，实际以台账与已批预算为准）：

```text
本期兑现清单
  加薪：{x}%                  例：10%【经验，随预算池与档位差变】
  晋升：{当前级} → {目标级}    例：P6 → P7（状态：待答辩）
  奖金：{n} 个月              例：2 个月【经验，随公司奖金池与档位变】
  未兑现项：{承诺内容} → {为什么变} → {何时重看}
```

注意第二行的「待答辩」：晋升兑现的常见状态不是「已给」，而是「已进入流程」。**把状态说清楚，比把话说满更有用**——「待答辩」是可核验的状态，「应该没问题」不是。

### 10.2 脚本骨架（可套用）

```text
第一段｜目的：先给结论，不做铺垫
    「{周期}的结论是：{加薪 x% / 晋升到 Y / 奖金 n 个月}。我先说完，再讲为什么。」
第二段｜目的：给依据——回到事先写死的判据与事实，不说「你表现不错」
    「判断依据是 {证据时间线里的两条事实}，对的是我们 {上一周期} 写死的 {判据 / 锚点}。」
第三段｜目的：把未兑现项主动说完，给原因，给重看时间
    「还有一条本期没兑现：{承诺内容}。变化的原因是 {原因}。这条我写进台账，{日期}重新看。」
第四段｜目的：把物质之外的兑现落到具体的东西上，不用形容词
    「除了钱，本期还有 {Title / 带人范围 / 项目机会 / 会议名额}；配套的要求是 {…}。」
第五段｜目的：把下一步写进日历，并指出申诉通道
    「下一次复核是 {日期}，我发个邀请。对这次的结论有异议，走 {申诉路径}，不经过我。」
```

最常被跳过的是**第三段**。跳过它当场不会出事，员工多半也不追问；但被漏掉的承诺会在下一个周期以「你上次说过」的形式回来，而且发现渠道已经从「主管说明」变成了「跟同事对比」——到那时兑现信用已在折价，且按 §3.2.7 不可逆。第二段也常被缩成一句「你表现不错」：没有判据的兑现，等于当面告诉员工这个数是我拍的，下一轮他会把力气花在让你看见，而不是花在事上。

```text
兑现话术的对照（同一件事，两种说法留下的东西不同）
   ✗「今年整体不错，也考虑到团队平衡，给你涨 {x}%」
       → 依据是「平衡」，员工学到的是下次要靠比较，不是靠做事
   ✗「你表现挺好的，所以给你 {n} 个月」
       → 依据是印象，下一轮他会来谈印象
   ✓「你上季度把 {事} 从 {基线} 做到 {结果}，按我们 {日期} 写死的判据是 {档}，
      对应加薪 {x}%」
       → 依据事先存在，员工学到的是判据可预期
────────────────────────────────────────
自查一句话：把这段话录下来，删掉数字，剩下的句子还剩下几条事实
```

**中止条件**：如果员工当场提出的是事实分歧（「那个项目我没拿到数据权限」），不要在现场重新讨论评级——把分歧记进申诉通道，按流程处理。当场改结论，等于告诉全组「结论可以谈出来」。

**该带什么材料进来**（缺哪一样，对方一定会绕开你的论点）：

- **兑现台账**：每条承诺 → 承诺人 → 到期日 → 状态（已兑现 / 已书面说明）
- **上一轮的面谈记录**：结论 + 证据时间线 + 未兑现说明的原文
- **本期预算池的口径与上限**——解释「为什么是这个数」时唯一站得住的东西
- **申诉路径的书面说明**（找谁、多久内答复、由谁裁定）
- **PIP 模板**——本期结论是不达标时，兑现出去的是一份流程，不是一笔钱：

```markdown
# PIP - {员工姓名} - {周期}

## 背景
- 季度 OKR 完成度 {0.0–1.0}（示例：0.3）
- 主管多次反馈未改进
- 360 评估显示协作问题严重

## 改进目标（30-90 天）
1. 项目交付：按时交付率 ≥ 90%（当前 50%）
2. 沟通协作：跨团队满意度 ≥ 3.5/5（当前 2.5）
3. 学习：完成指定技术培训并通过考核

## 资源
- 导师：{P7+ 资深员工}
- 培训：{具体课程}
- 1:1 频率：每周 2 次

## 评估标准
- 30 天中期 Review
- 60 天深度 Review
- 90 天末次评估

## 评估结果（90 天后）
- 通过：转回正常绩效流程
- 不通过：转岗 / 协商离职 / 淘汰
```

模板里的数值全部是**示例填法**【经验，随岗位、法域与周期变】：真正的阈值没有通用值，只有在发出前写死的判据；周期 30–90 天【经验】沿主文件 §2.3 的口径，而「判据是否在开始前写明」才是这份模板有没有用的分界（自检见 §4.6）。

### 10.3 判据：说完之后怎么知道成了

| 判据 | 可观察的反应（对方做了什么 / 说了什么） | 为什么它说明成了 |
| --- | --- | --- |
| 记住的是依据而非数字 | 员工复述的是「因为 X 做成了 Y，所以是 Z 档」，而不是只记得那个百分比 | 说明第二段落地了；只记得数字的人，下一轮会把力气用在谈价上 |
| 问的是「下次什么时候」 | 员工对未兑现项追问重看日期，而不是重提旧承诺、或要求当场改结论 | 说明第三段接管了这条线索；重提旧承诺意味着台账说明没送到 |
| 日期进入日历 | 员工当场记下复核日期，或会后接受了你发来的日程邀请 | 下一步被双方之外的系统记得，不再依赖任何一方 |
| 状态被当作状态 | 面对「待答辩」，员工问的是答辩时间与评委是谁，而不是「你不是说定了吗」 | 说明状态与承诺被分开传递，没有把流程中的事说成已定的事 |
| 下一步落到他自己身上 | 员工复述的下一步是自己要做的动作（做哪个项目、什么时候找导师），而不是「公司会怎么安排」 | 兑现的落点回到了工作，而不是停在这笔钱上 |
| 不达标时能说出三件事 | 员工能说出 PIP 的判据、周期与申诉路径 | 说明交出去的是一份可执行的流程，而不是一场通知 |

```text
判据的写法（左边这种兑完就吵架）
   ✗「他没意见」                     → 不追问的理由太多，说明不了任何事
   ✗「他挺高兴的」                   → 情绪不是行为，且下周可能反转
   ✓「他复述了依据，并当场记下次复核日期」
   ✓「他追问的是重看时间，不是旧承诺」 → 线索被接管了
────────────────────────────────────────
自查一句话：这一列里有没有一个字是描述他当场做了什么
```

反向自查一遍：**员工说「理解」「谢谢」都不算判据**——当场不反对的理由太多（还没算清、不想撕破脸、在等同事情形）。判据只认他做了什么：追问、记录、发起邀请，或者当场提异议。

### 10.4 常见失败

| 失败形态 | 症状（怎么发现它） | 机制（为什么这么说会反噬） | 改法 |
| --- | --- | --- | --- |
| 先铺垫再给结论 | 开场的几分钟在讲团队成绩与个人成长 | 悬念期里员工会自己补一个更坏的版本，注意力全用在猜结果，后面的依据一句也没听进去 | 结论放第一句，依据放第二句 |
| 先兑现后沟通 | 数字已到账，谈话排在几天之后 | 员工把结果读成分配不公，而不是一次被解释过的判断——同一笔钱，说的顺序不同，留下的东西不同 | 面谈结论先行，谈话在到账前或当天完成（§4 Step 4） |
| 只谈已兑现、跳过未兑现项 | 台账上「待补说明」一栏长期空着 | 未兑现项不会消失，只是换了发现渠道：从你嘴里改成同事之间对比；一次漏兑现后，后续所有激励的折扣率上升且不可逆 | 每条未兑现项当面说完并写进台账，按季度对账 |
| 承诺时给区间、兑现时给下限 | 承诺记录写的是「我尽量争取」「应该没问题」 | 兑现日员工拿出来比的是承诺时的原话，含混措辞被系统性地听成上限；落差由此产生，责任还说不清在谁 | 承诺进台账时就写清承诺人、到期日与状态；给不了的口径当场说明 |
| 用 Title 顶替物质差额 | 该给的钱没给，多给了一个称呼或一个虚范围 | Title 的区分度靠稀缺性维持，贬值速度比奖金更快；用它顶差额等于同时稀释了下一个人的兑现空间 | 精神兑现也要有稀缺性约束，且不与物质差额做等价交换 |
| 拿同级同事做标尺 | 「这次比 X 少一点，因为…」 | 把一次判断变成排序争议，还泄露他人信息；员工此后只关心排序，不再关心判据 | 依据只回到事先写死的判据与本人事实，不用第三人做标尺 |
| 只谈钱、不谈别的兑现 | 谈话结束时员工只知道数字，不知道 Title / 范围 / 机会有变化 | 物质给不了的部分本可以用机会补，漏说等于把这一层的空间白白丢掉，而缺口仍留在员工心里 | 第四段照骨架说完，每一项兑现都写进台账 |
| 让 AI 起草兑现说明并直接发出 | 说明文本措辞漂亮，但答不上「这是哪条依据」 | 模型输出的是文本不是证据；兑现场合的每句话都要能追到台账与判据，追不到的部分会成为下一轮的争议入口 | AI 可用于整理时间线与初稿，发出前逐句核对是否都能追到台账 |

最危险的一条是**先兑现后沟通**：它不会当场报错，金额一分不少，员工也不会在会上说什么。代价在一个完整周期之后显形——员工把自己拿到的数跟同事的比，而不是跟事先写死的判据比；从那一刻起，所有关于「为什么是这个结果」的解释都变成了事后补话，而兑现信用一旦折价就不可逆。

### 10.5 接口

这套脚本不产生判断，只传递判断，所以它的输入全部来自本节之外：台账的字段与对账节奏在 [§4 工程实现](03-performance-management-section-4-sec4.md) Step 5，产出落在 [§4.5 模板 / 示例](03-performance-management-section-4-sec4.md) 模板四的第 5 节「激励兑现」；第一条依据（证据时间线）来自 Step 4 的面谈记录；「一次不兑现不可逆」这条约束与激励组合的三层结构（物质 / 精神 / 内在）出自 [§3.2.7](03-performance-management-section-3-sec3.md)，处置链（预警 → PIP → 再评估 → 决策 → 合规）出自 §3.2.6，本节第五段与不达标分支都沿用同一条链；「PIP 判据事前写死」这一条与 [§9](03-performance-management-section-9-sec9.md) 是同一条规则的两处落点；AI 只进证据、不进档位，三个角色（写证据 / 定级 / 受理申诉）彼此独立，见 [§5 前沿演进](03-performance-management-section-5-ai.md)。合规上有一件事必须先核：欧盟《人工智能法案》（Regulation (EU) 2024/1689，2024 年通过）把用于就业与员工管理的 AI 归入高风险类别【公开】，凡把自动化输出接进兑现环节的组织，落地前按当地要求核验告知、留痕、人工复核与申诉通道，具体以官方文本当前版本为准。

### 10.6 小结

兑现谈话的成败只取决于一个动作：**把未兑现项主动说完**。钱给多给少，员工记住的是数字；而兑现信用记住的是「你上次说的话算不算数」——它只折价、不累积，且按 §3.2.7 不可逆。所以这场谈话的目标不是让员工满意这一次，而是让他相信下一次的承诺仍然可以照台账来算。

> 💡 **思考锚点**：回到你上一次兑现谈话：第一句给的是结论还是铺垫，未兑现项是你主动说完的，还是员工追问出来的？再翻你自己的记录，判据那一列写的是他当场「做了什么」（追问、记录、发起邀请），还是「他挺高兴的」这种情绪词？按 §10.4，先兑现后沟通的折价要一个完整周期后才显形——你手上是否已经有一笔正处在这种不可逆的折价里？
