## 4. 工程实现

### 4.1 落地步骤

**Step 1：选择绩效模式（1-2 周）**

1. 团队规模 / 业务性质 / 文化成熟度。
2. 参考「**适用场景决策表**」。
3. 高管 + HRBP 共识。

**Step 2：设计目标体系（2-4 周）**

1. OKR 或 KPI 模板（公司级、团队级、个人级）。
2. 跨团队对齐（避免重复造轮子）。
3. 季度目标 Review 机制。

**Step 3：建立评估体系（2-4 周）**

1. 360 评估（自评 + 上级 + 平级 + 下级 + 跨部门）。
2. 9 宫格（绩效 × 潜力）。
3. 跨级评委 / 校准会。

**Step 4：建立反馈机制（持续）**

1. 季度 1-on-1。
2. Real-Time Feedback（Slack / Teams）。
3. 绩效面谈（每年 1-2 次 + 持续）。

**Step 5：设计激励组合（2-4 周）**

1. 物质激励：Base / Bonus / RSU。
2. 精神激励：Title / 晋升 / 认可 / Conference。
3. 内在激励：自主、专精、目的。
4. 末位处置：PIP + 转岗 + 淘汰。

### 4.2 关键技术点

**1. OKR 模板**

```markdown
# Q1 2026 OKR - 数据平台团队

## Objective（目标）
搭建行业领先的 AI 时代数据平台，支撑业务智能化升级

## Key Results（关键结果）

### KR1：完成 RAG 检索体系建设
- 0→1 上线，准确率 ≥ 85%
- 性能 P95 < 500ms，QPS ≥ 1000
- 跨 3 个业务线接入

### KR2：数据治理与质量提升
- 数据问题率 < 0.1%
- 数据 SLA ≥ 99.9%
- 完成指标平台 100+ 核心指标

### KR3：AI 能力建设
- 团队 100% 通过 LLM 基础培训
- 主导 2 个 LLM 微调 POC
- 输出 5 篇技术博客 / Conference 演讲

### KR4：组织能力
- 培养 2 个 P7 候选人
- 跨团队满意度 ≥ 4.5/5
- 团队 NPS ≥ 50

## 完成度（季度末打分）
- KR1: 0.7
- KR2: 0.8
- KR3: 0.6
- KR4: 0.7
- 综合: 0.7（卓越）
```
