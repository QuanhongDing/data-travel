# Ch14 · 团队管理与领导力

> **一句话定位**：带人、做事、影响组织——"技术牛"只是入场券，"团队能打仗"才是资深数据架构师。

## 画像映射

本章对应 **加分项**（招聘要求：5 人以上技术团队管理经验）—— 资深数据架构师 的"软分水岭"：

- **人才画像与招聘**：P5-P8 数据架构师 的人才模型、结构化面试、面试官培养
- **人才梯队与培养**：培养路径、晋升辅导、离职面谈——让 P7/P8 成长为下一个资深架构师
- **绩效管理与激励**：KPI / OKR 设计、绩效面谈、末位淘汰、激励组合
- **跨团队协作**：跨 BU 数据共享、冲突解决、同盟构建、影响无授权的团队
- **向上管理**：老板期望管理、资源争取、汇报技巧——把技术语言翻译成业务语言
- **团队拓扑**：Team Topologies、平台 / 业务 / 治理团队协作、流式对齐、认知负荷
- **文化建设**：故障复盘文化、技术分享、代码评审、知识沉淀——组织能力沉淀

> P7 是"独立贡献者"，P8 是"团队带头人"，**资深数据架构师是"组织影响者"**——能让一群人写出好代码，让一个组织持续进化。

## 本章要回答的核心问题

### 团队组建与人才招聘
1. 怎么画团队的**人才画像**？P5 / P6 / P7 / P8 各应该是什么样？能力模型与胜任力评估？
2. 面试官怎么培养？**结构化面试**怎么设计？如何在高密度招聘和"宁缺毋滥"之间平衡？

### 人才梯队与培养
3. 怎么搭建团队的**人才梯队**？P5 → 资深数据架构师 的培养路径是什么？IDP（个人发展计划）怎么设计？
4. **晋升答辩**怎么辅导？阿里 P7 → P8 / P8 → 资深架构师 的答辩套路与失败案例？
5. **离职面谈**怎么谈？如何识别"该走的人"和"该留的人"？

### 绩效管理与激励机制
6. **KPI vs OKR** 怎么选？数据团队的绩效怎么量化？
7. **绩效面谈**怎么做？末位淘汰怎么谈？
8. **激励**怎么设计？高薪、晋升、成长机会、成就感怎么组合？

### 跨团队协作与影响力
9. **跨团队协作**怎么搞？跨 BU 数据共享的博弈怎么解？
10. **影响无授权的团队**（Influence Without Authority）怎么做到？
11. **技术布道**怎么做？怎么让业务方主动用你的平台？

### 文化建设与价值观
12. **故障复盘文化**怎么建立？无指责、根因、行动项——把每一次故障转化为组织能力？
13. **技术分享文化**怎么运营？周会、Tech Talk、读书会——持续学习的组织机制？
14. **代码评审文化**怎么落地？CR 的标准与节奏——让代码质量成为团队习惯？

### 向上管理与业务沟通
15. **向上管理**怎么做？老板想要什么、你应该给什么——预期管理与资源争取？
16. **业务沟通**怎么搞？怎么把技术语言翻译成业务语言？
17. **资源争取**怎么谈？预算、HC、技术投入的 ROI？

### 远程与异步管理
18. **远程团队**怎么管？异步沟通、时区协调、信任建立——远程团队的文化建设？

### 团队节奏与组织设计
19. **周会 / 双月会 / 季度复盘**怎么设计？**小而美 vs 大而全**的团队设计原则？
20. **团队拓扑**（Team Topologies）：平台团队 / 业务团队 / 治理团队的协作与认知负荷？

## 画像能力小结

完成本章后，你应当能够：

| 能力维度 | P7 | P8 | 资深数据架构师 |
| --- | --- | --- | --- |
| 技术深度 | 单一领域专家 | 跨领域 | 跨领域 + 跨组织 |
| 团队管理 | 独立贡献者 | 带 3-10 人 | 带 20-50 人 / 跨团队 |
| 影响力 | 团队内 | 跨团队 | 跨 BU / 跨公司 |
| 业务理解 | 理解需求 | 理解业务 | 推动业务 |
| 决策 | 局部决策 | 局部决策 + ADR | 战略决策 |
| 文化建设 | 遵守规范 | 制定规范 | 建立文化 |

- **设计人才画像**：P5-P8 能力模型、结构化面试、面试官培养
- **搭建人才梯队**：培养路径、晋升辅导、IDP——让 P7/P8 成长为下一个资深架构师
- **设计 KPI / OKR 体系**：让团队目标可量化、可对齐、可复盘
- **推动跨团队协作**：跨 BU 数据共享、影响无授权的团队、技术布道
- **建立组织文化**：故障复盘、技术分享、代码评审——让组织能力沉淀
- **做好向上管理**：预期管理、资源争取、把技术语言翻译成业务语言
- **应用团队拓扑**：Team Topologies、平台 / 业务 / 治理团队协作、认知负荷管理
- **带 20-50 人 / 跨团队**：资深数据架构师 80% 的价值来自带人和影响组织，而非个人贡献
