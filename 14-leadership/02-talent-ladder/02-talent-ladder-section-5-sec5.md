**4. 离职面谈模板**

```markdown
# 离职面谈记录 - {员工姓名}

## 基本信息
- 姓名 / 工号 / 部门 / 直属经理 / 入职日期
- 提交离职申请日期 / 计划最后工作日
- 离职原因（员工自述）：______

## 5 类核心问题
### 1. 真实原因
- 薪酬？发展？老板？文化？工作生活平衡？
- 追问：「如果 [条件] 满足，你会留下吗？」

### 2. 组织反馈
- 你对团队 / 公司有什么建议？
- 哪个环节让你失望？

### 3. 挽留空间
- 是否愿意调整岗位 / 团队 / 工作内容？
- 是否需要调整薪酬？

### 4. 去向
- 下一站？什么吸引你？

### 5. 后续联系
- 是否愿意做校友 / 推荐人 / 客户？

## 分类与处理
- 离职原因分类：[薪酬 / 发展 / 老板 / 文化 / WLB / 个人原因]
- 是否 Regrettable：[是 / 否]
- 挽留决策：[挽留 / 接受]
- 改进措施：______
```

### 4.3 工具链与平台（含 2024-2025 新工具）

**职级与能力管理**：

- **传统**：SAP SuccessFactors、Workday、Oracle HCM。
- **现代**：Lattice、15Five、Glint（Culture Amp）、CultureAmp。
- **国内**：飞书 People、北森 People、Moka People。

**IDP 与学习**：

- **LinkedIn Learning**：7000+ 课程，AI 推荐。
- **Degreed**：技能图谱 + 学习平台。
- **国内**：极客时间、网易云课堂、慕课网、得到。

**AI 时代工具（2024-2025）**：

- **Eightfold Talent Intelligence**：Skills Graph + IDP 推荐。
- **Gloat**：内部人才市场 + AI 技能匹配。

- **Humu**：AI 驱动的员工敬业度调研。

- **ChatGPT Enterprise / Claude for HR**：HRBP 用 LLM 生成 IDP 草稿。
