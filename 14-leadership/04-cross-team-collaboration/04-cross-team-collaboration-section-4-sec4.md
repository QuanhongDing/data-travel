## 4. 工程实现

### 4.1 落地步骤

**Step 1：识别跨团队项目（持续）**

1. 列出需要 2+ 团队协作的项目。
2. 评估 Sponsor 支持度、利益复杂度。
3. 设立 Working Group / 项目组。

**Step 2：设计 RACI 矩阵（1-2 周）**

1. 列出所有活动。
2. 明确 A（每项 1 人）。
3. 列出 R / C / I。
4. 与 Stakeholder 沟通对齐。
5. 公示 RACI 矩阵。

**Step 3：建立 Stakeholder 管理（持续）**

1. Stakeholder 4 象限分析。
2. 分级管理策略。
3. 定期 Review 关系。

**Step 4：建立 Shared Service / Platform（2-6 月）**

1. 明确价值主张。
2. 设立团队（5-10 人）。
3. MVP 上线。
4. SLA 制定与监控。
5. 客户成功机制。

**Step 5：建立 CoE / Enabling Team（按需）**

1. 明确专业能力中心定位。
2. 设立团队（3-5 人）。
3. 输出方法论 + 最佳实践。
4. 项目制深入业务。

### 4.2 关键技术点

**1. RACI 模板**

```markdown
| 活动 | 业务方 | 数据架构师 | 数据工程 | 合规 | 高管 |
| --- | --- | --- | --- | --- | --- |
| 数据接入规范 | C | A | R | C | I |
| 血缘系统搭建 | C | A | R | C | I |
| 数据质量监控 | I | A | R | I | I |
| 数据 SLA 报告 | I | A | R | I | C |
| 跨 BU 治理会议 | C | A | R | C | I |
| 数据合规审计 | C | A | C | R | I |
```

**2. Stakeholder 管理模板**

```markdown
# 项目 Stakeholder 分析 - 数据中台

## 高利益 + 高权力（密切管理）
- CEO：每月 1:1 + 月报
- 业务一号位：每周 1:1

## 高利益 + 低权力（保持告知）
- 各 BU 业务方：周报、Slack
- 数据分析师：周会、培训

## 低利益 + 高权力（保持满意）
- HR 负责人：季度报告
- 合规负责人：季度审计
- CFO：ROI 季度报告

## 低利益 + 低权力（最少努力）
- 其他团队：年报、Wiki
```

**3. 跨团队会议模板**

```markdown
# 跨团队会议 - 数据中台周会

## 时间
每周二 10:00-10:45

## 参与者
数据架构师 / 各 BU 数据负责人 / 数据工程 / 合规（按需）

## 议程
1. 上周进展 Review（10 分钟）
2. 关键问题讨论（20 分钟）
3. 跨团队决策（10 分钟）
4. Action Items Review（5 分钟）

## 决策机制
- 现场决策：Sponsor + 数据架构师
- 复杂决策：升级到双周 Sponsor 会议

## 会议纪要模板
- 讨论议题
- 决策结论
- Action Items（负责人 + 截止日期）
```

**4. Shared Service SLA 模板**

```markdown
# 数据中台 SLA

## 可用性
- 核心数据管道可用率 ≥ 99.9%
- 查询响应 P95 < 5 秒
- 故障响应时间 < 30 分钟

## 接入支持
- 新业务接入平均 5 个工作日
- 文档完整度 100%
- 培训覆盖 100% 接入方

## 数据质量
- 数据准确率 ≥ 99.99%
- 数据完整性 ≥ 99.95%
- 数据时效性 < 1 小时

## 沟通机制
- 周会、月报、季度回顾
- 客户满意度 ≥ 4.5/5
- 投诉处理 < 24 小时
```

### 4.4 代码 / 示例

**示例 1：跨团队冲突解决（Win-Win）**

```
冲突场景：业务方 A 希望数据接入快速上线（愿意接受较低 SLA），
         业务方 B 要求高 SLA（可接受较慢上线）。

业务方 A 立场：3 周内上线，SLA 99%。
业务方 B 立场：SLA 99.99%，6 周内上线。

共同利益：双方都希望业务快速跑起来。

Brainstorm 方案：
1. 分阶段：MVP 3 周上线（SLA 99%），Q2 升级到 99.99%
2. 区分数据：核心数据 SLA 99.99%，辅助数据 SLA 99%
3. 共享基础设施：A、B 共同分摊成本

最终方案：方案 1 + 方案 2 组合
- 核心数据 99.99%，辅助数据 99%
- MVP 3 周，Q2 升级

双方共赢：
- 业务方 A：3 周上线，业务快速验证
- 业务方 B：高 SLA 保证，业务稳定
```
