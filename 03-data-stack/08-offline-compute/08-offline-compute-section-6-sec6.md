   - 关键能力：**全业务**

> **本节小结**：
> - 4 个真实案例（字节 / 阿里 / 腾讯 / Netflix）印证：**离线计算不是「**Hive 慢**」，是「**Spark + Iceberg + Flink + 流批共享**」**4 件套**。

> - 99% 的失败来自「**Hive 慢 + 冗余多 + 多业务不一致**」——必须有 **Spark + Iceberg + 流批共享 + 4-25 业务统一**。
> - 真正的 ROI 来自「**EB 级 + 0 冗余 + 13 亿+ / 2 亿+ 用户**」——是**大厂核心离线计算基础设施的命脉**。
