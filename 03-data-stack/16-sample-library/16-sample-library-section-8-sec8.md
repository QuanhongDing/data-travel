#### §8.1 你们模型的离线指标比线上好一截，怎么排查？为什么"调模型"不是第一步？

**1. 考察点**
- 是否知道**特征穿越会让离线指标更好看**，因此它不会引起怀疑；
- 有没有**机械检查**的意识（改连接条件重跑）；
- 是否理解"离线好线上差"的几种成因与排除顺序。

**2. 参考答案框架**

**第一层：先给出成因清单与排除顺序。** ① **特征穿越**（回填用了 `event_time` 之后的信息）；② 切分泄漏（实体 / 时间 / 近重复）；③ 训练线上一致性（特征计算的实现在两侧不同）；④ 评测集不代表线上分布（非随机抽样）。**顺序：先查 ①（因为它最隐蔽且影响最大），再查 ②③④。**

**第二层：给出穿越的机械检查。** **把回填的连接条件改成只允许 `feature_ts <= event_time`，重跑一次评测**——**指标明显下降，说明此前一直有穿越**。这个动作的成本是改一个条件加跑一次评测。

**第三层：说明为什么它最难发现。** **穿越的性质是"让离线指标更好看"**——因此它不会被任何指标暴露，反而会被当成"模型好"；**唯一的发现方式是检查连接条件本身**（§3.2.6）。

**第四层：给出诊断的分布特征。** 穿越的差异**集中在"时点之后仍会变化的特征"上**（窗口类特征如"最近 7 天消费额"），而快照类特征（注册渠道）几乎不受影响——**这条分布特征本身就是诊断依据**（§6.3）。

**3. 常见陷阱**
- 直接开始调模型 / 扩样本；
- 只答"做交叉验证"（那不能发现穿越）；
- 把"离线好"当成模型好的证据；
- 不知道要检查连接条件。

**4. 追问预测**
- "怎么量穿越的幅度？"
- "穿越幅度已知后，此前的模型结论怎么办？"
- "特征历史保留期不够，老样本回填不出来怎么办？"
- "训练与线上的特征计算实现在两侧不同，怎么发现？"

**5. 参考资料**
- 本主题 §2.2（点时正确的形式化）、§3.2.6（点连接）、§4.2（3）（回填两实现）、§6.3（穿越还账的案例）。

#### §8.2 训练集与测试集怎么切？有哪几种泄漏、各怎么检测？

**1. 考察点**
- 是否知道**三种泄漏**（实体 / 时间 / 近重复），而不是只知道"随机切分"；
- 有没有"三种检测各跑一次、各返回 0"的实践；
- 知不知道按主体重复时随机切分必然实体泄漏。

**2. 参考答案框架**

**第一层：先问"一个主体会不会贡献多条样本"。** 会 → **必须按实体切分**（同一实体的样本全在同一侧）；不会 → 随机切分合法。**这一问是切分方式的分水岭。**

**第二层：给出三种泄漏与检测。**

```
① 实体泄漏：同一实体跨集（按 entity 求交集，应为空）
② 时间泄漏：训练集与测试集时间交错（max(train.et) ≤ min(test.et)）
③ 近重复泄漏：同一内容以不同形式跨集（跨集相似度 > 阈值，应为 0 对）
判据：三种都要有检测脚本，且都在 CI 里阻断
```

**第三层：说清"按时间切分"的取舍。** 它最贴近线上（测试集是"未来"），且**天然防时间泄漏**；**代价是测试集只能是最近一段，样本量可能不足**。

**第四层：给出可复现要求。** **切分规则 + 随机种子 + 快照 id 三者一起记录**——否则同一次评测不可复现，而"结论不可复现"等于"结论不可比"。

**3. 常见陷阱**
- 只答"随机切分"；
- 只做实体检测（另外两种仍在漏）；
- 切分不留种子与快照（不可复现）；
- 不区分"实体可重复"与"不可重复"的业务。

**4. 追问预测**
- "按时间切分导致测试集样本太少怎么办？"
- "近重复的阈值怎么定？"
- "重新切分之后，历史结果怎么处理？"
- "OneID 不统一时，按实体切分会怎样？"

**5. 参考资料**
- 本主题 §2.2（三种泄漏的形式化）、§3.2.7、§4.2（4）（三脚本）、[Ch2 §01 特征平台](../../02-data-science/01-feature-store/01-feature-store.md)（点时正确性的同族问题）。

#### §8.3 你们打算用 LLM 预标注来扩大样本量，怎么保证质量不下降？

**1. 考察点**
- 是否知道**修正比例低有两种解释**（模型好 / 人在盲从）；
- 知不知道要**抽未修正批独立重标**；
- 有没有意识到**模型偏好会进入标签并被下一代模型学走**。

**2. 参考答案框架**

**第一层：先说清机制变化。** 标注从"判断"变成"确认"，**成本下降而样本量上升**；但**人倾向于确认看起来合理的候选**，于是**模型的系统性偏差进入标签**——**这个循环不表现为"标注质量差"，而表现为"模型与标注互相加强"**（§5.3.2）。

**第二层：给出验证动作（这是本题的关键）。** **从"未被修正"的样本里随机抽一批独立重标**，比较它与"被修正"批的准确率。**未修正批明显更低 ⇒ 人在盲从。**

**第三层：给出两条护栏。**
- **周期性的人工独立标注作为锚**（不参考模型候选）；
- **修正比例作为监控项而非质量指标**（它同时受模型质量与人是否盲从影响）。

**第四层：说清分区的必要性。** 预标注的输入语料**不能包含评测集的来源**——否则它会以改写形式把评测题带进训练集（**而那不是近重复，比对发现不了**，§3.2.8）。

**3. 常见陷阱**
- 只答"抽检"但抽的是"被修正"的那批；
- 把修正比例低当成模型好的证据；
- 不设独立锚（偏差持续累积）；
- 预标注流程能读到评测来源。

**4. 追问预测**
- "独立锚的规模要多大？多久做一次？"
- "如果未修正批准确率确实低，你怎么办？"
- "模型候选的置信度能不能用来分层审核？"
- "预标注与合成数据混用时会怎样？"

**5. 参考资料**
- 本主题 §3.2.4（预标注 + 人审的失效点）、§5.3.2（LLM 预标注的偏差循环）、§4.2（6）（合成分区）。

#### §8.4 标注口径怎么写？为什么"边界案例"比"判定问题"更重要？

**1. 考察点**
- 是否知道**分歧集中在口径未覆盖的边界上**；
- 知不知道 κ 是**口径的诊断**而不是**标注者的考核**；
- 有没有"任务配置五部分"的概念。

**2. 参考答案框架**

**第一层：给出任务配置的五个部分。** 输入展示 / 判定问题 / 取值域 / **边界案例（3–5 个）** / 审核规则（§6.1）。**边界案例是口径的主要载体**——判定问题决定任务看起来在做什么，**边界案例决定它实际怎么做**。

**第二层：说清为什么边界案例更重要。** 因为**分歧出现在"判定问题没说清"的地方**，而那些地方**只能靠案例来固定**（"问一下会员权益有哪些"算不算资金类——这句话本身说不清，给一个例子就清楚了）。

**第三层：给出一致性的用法。** 抽样重复标注算 **κ + 分歧分布**：**分歧集中 ⇒ 补边界案例；分歧均匀 ⇒ 任务定义有问题（缩小范围）**。**κ 衡量的是口径的清晰程度，不是标注者的水平**——拿它考核会让人彼此对齐，从而掩盖口径问题。

**第四层：给出一条验收判据。** **让一个新人只看任务配置（不看口头说明）开工**——**被卡住的地方就是配置缺的部分**。

**3. 常见陷阱**
- 口径写在一份共享文档里（与任务的对应靠人维护）；
- 只写判定问题与取值域；
- 拿 κ 考核标注者；
- 边界案例选的不是真正分歧的地方。

**4. 追问预测**
- "边界案例选几个？谁来选？"
- "κ 低的时候你第一步做什么？"
- "新任务的口径怎么从零建立（没有历史分歧数据）？"
- "主观性强的任务（如'有没有风险'）怎么处理一致性？"

**5. 参考资料**
- 本主题 §2.2（κ 与分歧分布）、§3.2.1（任务配置化）、§4.2（2）（一致性诊断脚本）、§6.1（口径写进任务流的案例）。

#### §8.5 你们的评测集怎么保证没被污染？为什么"训练集和测试集不重叠"不够？

**1. 考察点**
- 是否知道**污染有直接与间接两种**；
- 有没有**来源台账**的意识；
- 知不知道合成数据会带来自证风险。

**2. 参考答案框架**

**第一层：区分两类污染。**
```
① 直接污染：评测样本（或近重复）出现在训练数据里 → 可**比对发现**
② 间接污染：经由公开语料 / 合成数据 / 改写带进来 → **比对发现不了**
```

**第二层：给出三件检查。** 跨集近重复比对 / 来源语料比对 / **数据来源台账**——**前两件是机械检查（便宜、可自动），第三件是流程约束，而它是唯一能挡间接污染的一件**。

**第三层：说清"来源台账"为什么不可替代。** 因为**"这份公开语料里有没有我的评测题"这个问题，在下载时就已经无法回答**（语料是黑箱）——**只有"每个来源登记它可能包含什么"这条陈述能在当时把它记下来**。

**第四层：说清合成数据的自证风险。** **用含评测题的语料生成样本 ⇒ 合成样本带着评测题进入训练集，而它是改写的、不是近重复**。**唯一手段是分区隔离**（合成流程的输入语料与评测集来源物理分开）+ 把合成产出的来源登记进台账。

**3. 常见陷阱**
- 只答"我们做过去重"（那只覆盖直接污染）；
- 不做来源台账；
- 把合成数据当成"干净的扩量手段"；
- 合成流程能读到评测来源。

**4. 追问预测**
- "近重复的阈值怎么定？改写程度多大会漏？"
- "台账每个来源要登记什么字段？"
- "如果发现污染，此前的结论怎么办？"
- "对外评测（第三方榜单）的污染怎么处理？"

**5. 参考资料**
- 本主题 §2.2（两种污染与检测）、§3.2.8（污染检查与台账）、§4.2（5）（6）、§5.3.3（合成数据的自证风险）、§6.4（间接污染的案例）。

#### §8.6 主动学习能省多少标注？为什么它不能用来做评测集？

**1. 考察点**
- 是否理解主动学习**改变训练集分布**；
- 知不知道**评测集必须随机抽样**（它要代表线上）；
- 有没有"边标边重训"的意识。

**2. 参考答案框架**

**第一层：先说清它省的是什么。** 它把预算从"均匀覆盖"改成"投在决策边界上"——**而模型的提升恰恰来自边界样本**（已能正确判的样本标了也不改变模型）。**因此省的是"无效标注"的那部分。**

**第二层：给出它的硬前提。** **边标边重训**（§2.2 的判据）——一次性选完再标，等价于只用最初那个模型的不确定度去挑，**收益随轮次迅速衰减**。

**第三层：说清为什么不能做评测集（本题关键）。** **评测集的全部意义是"代表线上分布"**，而**主动学习样本恰恰不代表线上分布**（它偏向模型的不确定区域）。**用它做评测，等于"用边界样本评一个为边界优化的模型"**——指标会高，且**不能外推到线上**。

**第四层：给出正确的组合。** **三类来源各司其职**：主动学习样本喂训练 / **随机抽样做评测** / 线上回流贴近线上（但要**绑曝光策略版本**处理偏置）。

**3. 常见陷阱**
- 把主动学习样本也当评测集；
- 不做"边标边重训"（一次选完）；
- 忽略冷启动时模型太差、不确定度不可靠；
- 把回流样本当无偏样本用。

**4. 追问预测**
- "不确定度怎么定义（熵、投票分歧、预期模型变化）？"
- "冷启动时怎么选第一批？"
- "主动学习选出来的样本分布偏差，对线上评估有什么影响？"
- "回流样本的曝光偏置怎么处理？"

**5. 参考资料**
- 本主题 §2.2（信息增益的分配）、§3.2.3（主动学习与失效点）、§3.2.5（回流的有偏采样）、§5.3.4（主动学习与弱监督的边界）。
