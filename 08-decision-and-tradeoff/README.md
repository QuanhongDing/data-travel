## 本章要回答的核心问题

1. **架构决策记录（ADR）**怎么写？怎么让组织从"个人决策"走向"集体决策"？
2. **选型决策框架**是什么？性能 / 成本 / 团队匹配度 / 生态 / 可治理性如何权衡？
3. **自研 vs 采购**怎么判断？什么必须自研、什么可以采购、什么是"伪自研"？
4. **风险评估**怎么做？FMEA、故障树分析如何落地？
5. **技术战略** 3-5 年路线图怎么写？怎么让老板和团队都买账？
6. **技术债**怎么管理？什么时候该还、什么时候该拖、怎么量化？

## 与 P9 能力的对应

> **P8 能执行，P9 能决策**。

决策能力是 P8 → P9 的真正分水岭。技术深度可以通过学习获得，但**在不确定性中做出正确决策**的能力只能通过刻意练习。P9 必须能：

- **写出有说服力的 ADR**：让决策过程可追溯、可讨论、可被未来质疑
- **拒绝"伪自研"诱惑**：很多团队为了"掌控感"自研，结果维护成本爆炸
- **设计组织级技术决策流程**：从"个人拍板"到"集体决策"的演进
- **写出让老板买单的技术战略**：把技术规划翻译成业务价值
- **管理技术债而非被技术债管理**：识别、量化、优先级、还债节奏
