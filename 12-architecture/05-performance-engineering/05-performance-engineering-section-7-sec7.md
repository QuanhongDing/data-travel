### 7.2 决策树

```
你的瓶颈在哪里？
├─ 前端 → CDN + 资源优化
├─ 网络 → HTTP/2 + gRPC + TLS 1.3
├─ 应用 → JVM + 缓存 + 异步
├─ 数据库 → 索引 + SQL + 分库分表
└─ AI 推理 → 量化 + vLLM + KV Cache
```

### 7.3 组合使用

性能工程通常与其他手段组合：

- **性能工程 + 容量规划**：性能优化降低单位消耗。
- **性能工程 + 大促保障**：性能优化降低大促压力。
- **性能工程 + AI 优化**：AI 时代性能优化新维度。
- **性能工程 + 可观测性**：可观测性是性能工程的"眼睛"。
