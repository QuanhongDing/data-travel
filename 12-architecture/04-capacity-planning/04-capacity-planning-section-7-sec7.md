## 7. 与其他方法对比

### 7.1 对比维度（评分 1-5）

| 维度 | 拍脑袋 | ARIMA | Prophet | LSTM/Transformer | AI 辅助 |
| --- | :---: | :---: | :---: | :---: | :---: |
| 预测精度 | 2 | 3 | 4 | 5 | 5 |
| 易用性 | 5 | 3 | 5 | 2 | 4 |
| 可解释性 | 3 | 5 | 4 | 2 | 3 |
| 处理节假日 | 1 | 2 | 5 | 4 | 5 |

### 7.2 决策树

```
你的业务类型？
├─ 稳态业务 → ARIMA / 简单基线
├─ 周期性业务 → Prophet（电商、零售）
├─ 非线性 / 突变 → LSTM / Transformer
└─ AI 辅助决策 → LLM-based 容量规划

你的资源类型？
├─ CPU / 内存 → K8s HPA + VPA + CA
├─ GPU → GPU 池化 + Spot + Serverless
├─ 数据库 → 读写分离 + 分库分表 + 弹性
└─ 网络 → CDN + 弹性带宽
```

### 7.3 组合使用

容量规划通常与其他手段组合：

- **容量规划 + 大促保障**：峰值预测 + 峰值执行。
- **容量规划 + 性能工程**：性能优化降低单 Pod 消耗。
- **容量规划 + 弹性扩容**：预测 + 执行。
- **容量规划 + 成本优化**：精准预测 + 精准采购。
- **容量规划 + AI**：AI 辅助预测、决策。

**最佳实践组合**：

```
[历史数据] → [Prophet / LSTM] → [预测值]
    ↓
[业务叠加] → [业务驱动的预测]
    ↓
[资源评估] → [资源需求清单]
    ↓
[弹性扩容 / Spot] → [执行]
    ↓
[AI 辅助] → [持续优化]
```
