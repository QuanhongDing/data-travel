### 7.2 决策树

```
你的业务可用性要求？
├─ 99% → 冷备
├─ 99.9% → 温备
├─ 99.99% → 热备 / 同城双活
└─ 99.999% → 异地多活

你的 RPO 要求？
├─ 天级 → 冷备
├─ 小时级 → 温备
├─ 分钟级 → 热备
└─ 秒级 → 同城双活 / 异地多活
```

### 7.3 组合使用

- **容灾 + 单元化**：单元化让容灾粒度更细。
- **容灾 + 异地多活**：异地多活是容灾的高级形态。
- **容灾 + 混沌工程**：验证容灾流程。
- **容灾 + 大促保障**：大促前的容灾演练。
