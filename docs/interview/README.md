# 数据架构师面试题库

> 面向阿里数据架构师 / 字节 4-1 / 美团 L8 等资深数据架构师岗位的面试准备资料。

## 为什么需要这个目录

> **数据架构师面试 ≠ 技术问答，而是"模拟你的日常决策"**。

数据架构师面试官会通过以下几类问题考察候选人：

1. **系统设计题**：在白板上设计一个"实时数据管道"、"湖仓一体平台"、"指标平台"
2. **选型决策题**：在 Iceberg vs Hudi vs Paimon 之间怎么选？为什么？
3. **故障复盘题**：讲一个你主导过的最严重的故障，你怎么复盘？
4. **团队管理题**：你怎么带 20-50 人的团队？怎么处理跨团队冲突？
5. **战略决策题**：未来 3-5 年数据架构的演进方向是什么？你的判断依据是什么？

本目录按上述 5 类组织面试题与参考答题思路，另设「数据架构师晋升答辩」专项。

## 答题框架

每道面试题按以下结构组织：

```
1. 题目（真实或改编）
2. 考察点（面试官在考什么）
3. 参考答案框架（高分回答的结构）
4. 常见陷阱（低分回答的反模式）
5. 追问预测（面试官可能追问的方向）
6. 参考资料
```
