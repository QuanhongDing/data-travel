# 数据架构师面试题库

> 面向阿里 数据架构师 / 字节 2-2 / 美团 L8 等资深数据架构师岗位的面试准备资料。

## 为什么需要这个目录

> **数据架构师面试 ≠ 技术问答，而是"模拟你的日常决策"**。

数据架构师面试官会通过以下几类问题考察候选人：

1. **系统设计题**：在白板上设计一个"实时数据管道"、"湖仓一体平台"、"指标平台"
2. **选型决策题**：在 Iceberg vs Hudi vs Paimon 之间怎么选？为什么？
3. **故障复盘题**：讲一个你主导过的最严重的故障，你怎么复盘？
4. **团队管理题**：你怎么带 20-50 人的团队？怎么处理跨团队冲突？
5. **战略决策题**：未来 3-5 年数据架构的演进方向是什么？你的判断依据是什么？

本目录按上述 5 类组织面试题与参考答题思路。

## 子主题（占位）

- [ ] **系统设计**：实时数据管道、湖仓一体平台、指标平台、DataAgent、Feature Store
- [ ] **选型决策**：存储引擎、计算引擎、OLAP 引擎、向量库、AI 原生数据库
- [ ] **故障复盘**：真实故障案例复盘、5 Whys、根因分析、行动项设计
- [ ] **团队管理**：人才画像、绩效面谈、跨团队协作、向上管理
- [ ] **战略决策**：技术战略 3-5 年规划、技术雷达、组织演进
- [ ] **数据架构师晋升答辩套路**：晋升答辩、述职模板、能力举证

> 文件命名建议：`system-design-*.md` / `tech-selection-*.md` / `postmortem-*.md` / `team-management-*.md` / `strategy-*.md` / `promotion-defense.md`

## 答题框架

每道面试题按以下结构组织：

```
1. 题目（真实或改编）
2. 考察点（面试官在考什么）
3. 参考答案框架（高分回答的结构）
4. 常见陷阱（低分回答的反模式）
5. 追问预测（面试官可能追问的方向）
6. 参考资料
```
