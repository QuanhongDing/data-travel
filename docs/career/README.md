# 数据架构师成长路径

> 从 P7 到 数据架构师 的能力跃迁地图，以及如何规划你的 3-5 年成长路径。

## 为什么需要这个目录

> **技术能力有 S 型曲线，P7→P8 靠努力，P8→数据架构师 靠"换跑道"**。

很多 P8 工程师努力 3-5 年仍然上不去 数据架构师，核心原因不是技术不够深，而是**没有完成从"技术贡献者"到"团队领导者"的角色转换**。本目录帮助你：

1. 看清 P7→P8→数据架构师 的**能力差**是什么
2. 规划你的**3-5 年成长路径**
3. 避开常见的**晋升陷阱**

## 数据架构师能力对照表

| 能力 | P7 | P8 | 数据架构师 |
| --- | --- | --- | --- |
| 技术深度 | 单一领域专家 | 跨领域（数仓+实时+OLAP） | 跨领域 + 跨组织（推动技术演进） |
| 团队规模 | 独立贡献者 | 带 3-10 人 | 带 20-50 人 / 跨团队协调 |
| 影响力半径 | 团队内 | 跨团队 | 跨 BU / 跨公司 |
| 业务理解 | 理解需求 | 理解业务 | 推动业务 |
| 决策半径 | 局部决策 | 局部决策 + ADR | 战略决策 + 组织级规范 |
| 文化建设 | 遵守规范 | 制定规范 | 建立文化 |
| 业务沟通 | 与 TL 沟通 | 与业务方沟通 | 与 VP / CEO 沟通 |
| 风险管理 | 识别风险 | 缓解风险 | 主动管理风险 |
