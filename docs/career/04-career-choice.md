# 职业选择（Career Choice）

> **核心定位**：选对公司 / 业务 / leader / 团队——比个人能力更重要。这是很多 P7 / P8 后悔的根源。

## 职业选择的 4 大维度

### 维度 1：选公司（大厂 / 独角兽 / 创业 / 外企）

| 类型 | 优势 | 劣势 | 适合 |
| --- | --- | --- | --- |
| **大厂**（阿里 / 字节 / 美团 / 腾讯）| 体系完善 / 业务复杂 / 职级标准 | 螺丝钉 / 创新慢 / 政治复杂 | 想系统训练 / 看重 title / 长期发展 |
| **独角兽**（快速成长期公司）| 业务快速增长 / 全栈机会 / 影响力大 | 体系不完善 / 加班多 / 不稳定 | 想快速成长 / 接受风险 / 想要股权 |
| **创业公司**（A 轮之前）| 0 → 1 经历 / 股权 / 创始人近距离 | 不稳定 / 工资低 / 加班极多 | 想成为 0→1 选手 / 有创业意愿 |
| **外企**（Microsoft / Google / Netflix / Stripe）| WLB / 工程师文化 / 国际化 | 晋升慢 / 创新在中国本土慢 | 想 WLB / 想接触前沿技术 |

### 维度 2：选业务（朝阳 / 成熟 / 夕阳）

| 业务 | 特点 | 数据架构师视角 |
| --- | --- | --- |
| **AI 平台 / 大模型** | 资源密集 / 竞争激烈 | 挑战大 / 投入大 / 风险高 |
| **电商 / 零售** | 实时推荐 / 画像 / 库存 | 数据量大 / 业务经典 / 工具成熟 |
| **金融**（银行 / 证券 / 保险）| 合规严 / 数据治理 | 强治理 / 高可用 / 合规要求 |
| **内容 / 短视频** | 推荐 / 实时 / 海量 | 实时链路 / 大数据量 |
| **游戏** | 玩家画像 / 反作弊 | 海量 / 实时 / 复杂场景 |
| **政企**（能源 / 制造）| 数字化转型 / 数据中台 | 治理 / 中台 / 信创 |
| **SaaS / 工具** | 数据驱动增长 / AB 实验 | 增长 / 指标 / 实验 |

**建议**：在你职业早期，选「**业务复杂 + 数据量大**」的公司（如电商 / 内容 / 金融），能在 3-5 年内做很多项目。

### 维度 3：选 leader（直属 / 隔级）

**好 leader 的 5 个特征**：
- [ ] **愿意教**：能给你 1:1，能解答你的问题
- [ ] **敢放权**：给你独立负责的项目
- [ ] **业务理解深**：能讲清业务 / 数据 / 技术的全貌
- [ ] **为人正直**：不会抢功 / 不会甩锅
- [ ] **关注成长**：会主动帮你规划 / 推动晋升

**坏 leader 的 5 个信号**：
- ❌ 不愿意教 / 抢活 / 抢功
- ❌ 只关注产出，不关注人
- ❌ 不给你独立项目，永远让你当螺丝钉
- ❌ 政治复杂 / 办公室政治
- ❌ 自己都没想清楚，让你做

**怎么判断**：
- 面试时观察 leader 的提问质量
- 面试时观察 leader 对你未来 1-2 年规划的清晰度
- 面试时问「您的团队最大的痛点是什么」—— 看他是否真诚
- 面试时问「您团队成员的成长路径」—— 看他是否真关心人
- 找前员工 / 脉脉 / LinkedIn 打听

### 维度 4：选团队（业务 / 团队 / 文化）

| 团队 | 特征 |
| --- | --- |
| **业务核心团队** | 资源多 / 关注多 / 压力大 / 成长快 |
| **业务边缘团队** | 资源少 / 关注少 / 压力小 / 成长慢 |
| **新业务团队** | 0 → 1 / 全栈 / 影响力大 / 风险高 |
| **成熟业务团队** | 稳态 / 维护多 / 创新少 |
| **AI 优先团队** | 前沿 / 变化快 / 数据栈新 |
| **传统行业数字化团队** | 挑战大 / 周期长 / 治理多 |

**建议**：在你 P5-P6 阶段，去「**业务核心 + 新业务**」团队；在 P7-P8 阶段，去「**业务核心 + 成熟业务**」团队（稳态 + 影响力）。

## 职业选择的 3 大原则

### 原则 1：先选 leader，再选公司

- 一个**好 leader + 烂公司**，比**烂 leader + 好公司**成长快 5 倍
- 好 leader 会帮你规划、推动、扛事
- 烂 leader 会抢功、甩锅、压榨

### 原则 2：先选业务，再选技术

- **业务的天花板 = 你的天花板**：夕阳业务里你做得再好也没用
- **业务的发展速度 = 你的发展速度**：快业务 1 年顶慢业务 3 年
- **业务的复杂度 = 你的复杂度**：简单业务做不出复杂技术

### 原则 3：先选平台，再选薪资

- **平台 = 你的能力放大器**：在大平台你能做千万级 / 万人级的事
- **大平台的职级 = 你的市场价值**：跳槽时大厂 P7 / 3-1 远比小公司 CTO 受欢迎
- **大平台的人脉 = 你终身资产**：同级别的人脉在跨公司时价值连城

## 3 个职业选择常见陷阱

### 陷阱 1：只看薪资

- 短期看薪资，长期看平台
- 50% 涨薪 + 1 个好 leader，比 30% 涨薪 + 1 个烂 leader 强 5 倍
- 好的公司 / 团队 / leader 1 年能让你涨 2-3 倍，烂的 1 年让你降 50%

### 陷阱 2：盲目追风口

- 风口 3-5 年换一波
- 风口 = 行业 + 业务 + 团队 + 个人能力匹配
- 追风口前问自己：「这个风口的核心能力要求是什么？是我擅长的吗？」

### 陷阱 3：为了 title 跳

- Title ≠ 实际能力
- 「资深工程师」是 title，「独立 hold 一个 5 人项目」是能力
- 选「能给你能力 + 经验 + 人脉」的 offer，比选「title 好看但学不到东西」的 offer 强

## 关键决策框架

**当你收到多个 offer 时，按以下顺序决策**：

1. **必杀条件**（必须满足）：
   - leader 是否好（最重要）
   - 业务是否在增长
   - 薪资是否合理（不要求最高，但不能低于市场 30%）

2. **重要条件**（满足越多越好）：
   - 团队是否核心
   - 平台是否大
   - 技术是否前沿

3. **锦上添花**（加分项）：
   - title
   - 股权
   - 福利

**如果「必杀条件」不满足，再多钱也不去。**
