# 心态建设（Mindset）

> **核心定位**：长期主义、延迟满足、失败复盘 —— 这些「软」的东西，最终决定你能走多远。

## 长期主义 vs 短期主义

### 短期主义者的 5 个信号

- ❌ 「这周能不能上线」（不在乎 6 个月后能不能 hold）
- ❌ 「这个 Q 能不能完成 KPI」（不在乎 1-2 年后有没有成长）
- ❌ 「能不能少干点」（不愿意为未来投资）
- ❌ 「领导不关注」（不主动争取 / 主动汇报）
- ❌ 「这家公司不行就跳」（不深耕任何领域）

### 长期主义者的 5 个特征

- ✓ 愿意**为 6 个月后的收益**做当下看起来不紧急的事
- ✓ 愿意**为 1-2 年后的成长**做当下看起来「不划算」的事
- ✓ 愿意**为 3-5 年后的能力**深耕一个领域
- ✓ 愿意**为 10 年后的自己**建立人脉 / 行业品牌
- ✓ 愿意**为终身成长**持续学习 / 复盘 / 反思

## 延迟满足（Delayed Gratification）

### 1 年的延迟 vs 3 年的延迟

**1 年延迟**：
- 现在不做 1-2 个 KPI 项目，去做 1 个 1 年才见效的平台项目
- 现在不拿 30% 涨薪去跳，去拿 1 个好 leader 的 offer
- 现在不写重复的 ETL 代码，去写 1 个跨团队工具

**3 年延迟**：
- 现在不在小红书上刷 30 分钟，去读 1 篇 Netflix Tech Blog
- 现在不抱怨 30 分钟，去做 1 个 1% 的项目改进
- 现在不参加 1 个没意义的会议，去做 1 个有意义的项目

### 5 个延迟满足的实践

- **每天 1 小时深度学习**：5 年 = 1825 小时 = 1.5 个大学学位
- **每周 1 篇技术博客**：5 年 = 260 篇 = 行业话语权
- **每月 1 次深度复盘**：1 年 = 12 次 = 显著成长
- **每季度 1 次职业评估**：5 年 = 20 次 = 清晰路径
- **每年 1 次跨领域尝试**：5 年 = 5 个新领域 = T 型 / π 型

## 失败复盘（Failure Recovery）

### 3 个真实失败案例

**失败 1：错误的晋升推荐**
- 现象：把一个 P6 推到 P7，6 个月后发现他明显撑不住
- 原因：看 PPT 太草率，没看 6 个月后的表现
- 学到：晋升要看 6 个月后的能力，不是答辩时的表现
- 改进：现在我会要求 3-6 个月的「试岗期」

**失败 2：错误的技术选型**
- 现象：2 年前选了一个大数据框架，1 年后被官方弃用
- 原因：只看 GitHub Star 数，没看 issue 关闭率 / 维护活跃度
- 学到：选型要看「未来 3 年的维护活跃度」，不是「现在 Star 数」
- 改进：现在我会做「技术雷达」（每季度评估在用技术）

**失败 3：错误的人**
- 现象：3 年前招了 1 个 P7，1 年后表现不佳，最终淘汰
- 原因：招聘时看技术深度，没看价值观 / 协作能力
- 学到：招人要看「价值观 / 协作能力 / 成长意愿」，不只是技术
- 改进：现在我会让候选人做 1-2 个团队协作的小项目

## 抗压能力

### 5 类常见压力

- **业务压力**：业务出问题 / 上线延期 / 数据事故
- **团队压力**：核心人员离职 / 团队冲突 / 招聘难
- **跨团队压力**：被其他团队 diss / 跨 BU 推动困难 / 政治复杂
- **个人压力**：晋升卡壳 / 转型失败 / 行业变化快
- **生活压力**：家庭 / 健康 / 兴趣 vs 工作的平衡

### 抗压的 5 个方法

- **第 1 个方法：接受压力是常态**—— P7+ 一定有压力，没压力说明你不在关键岗位
- **第 2 个方法：分清可控 vs 不可控**—— 只在「可控」上花时间，「不可控」上放下
- **第 3 个方法：找支持系统**—— mentor / 朋友 / 家人 / 心理医生
- **第 4 个方法：保持身体**—— 运动 / 睡眠 / 饮食，P7+ 是 5-10 年的长跑
- **第 5 个方法：留 hobby**—— 不能 100% 工作，否则会 burnout

## 终身成长（Continuous Learning）

### 5 个高效学习方法

- **边做边学**（90/10 法则）：10% 时间学新东西，90% 时间在项目里用
- **教是最好的学**：写 blog / 做分享 / 培训新人
- **读书 + 实战**：每年读 5-10 本技术书，每本应用 1-2 个项目
- **跨界学习**：学 1 个非技术领域（产品 / 设计 / 商业），开拓思维
- **反向学习**：学「反例」—— 看失败的案例，比成功的更有启发

### 5 个信息源

- **大厂技术博客**：Netflix Tech / Uber Engineering / Airbnb Engineering / LinkedIn Engineering / AWS Architecture
- **会议**：KubeCon / QCon / ArchSummit / Strata / OSC / Data + AI Summit
- **论文**：SIGMOD / VLDB / OSDI / ICDE / NSDI / OSDI
- **开源项目**：Apache / CNCF / Linux Foundation
- **行业报告**：Gartner / Forrester / 信通院 / DAMA

## 关键心态：3 个长期主义

### 心态 1：**做正确的事，不做容易的事**

- 容易的事 = 短期 KPI / 重复工作 / 讨好领导
- 正确的事 = 长期能力 / 体系 / 人才

### 心态 2：**先想，再做**

- 不要「接到任务就做」
- 先想 5 分钟：「这个事的根因是什么？有没有更好的做法？」
- 5 分钟能省 5 小时

### 心态 3：**让 1+1>2**

- 不要做「独狼」
- 找 1-2 个同级别 / 高 1 级的伙伴
- 互相 review / 一起学习 / 互相激励
- 5 年后你会发现：你的能力 ≈ 你身边 5 个人的平均
