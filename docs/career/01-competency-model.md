# 数据架构师能力模型（P5-P8）

> **核心定位**：P5 / P6 / P7 / P8 各级数据架构师的核心能力差异——回答「我现在在哪一级 / 下一级要补什么」。

## 四级能力对照

| 能力 | P5 工程师 | P6 高级工程师 | P7 技术专家 | P8 资深架构师 |
| --- | --- | --- | --- | --- |
| **技术深度** | 单一模块熟练 | 1 个技术方向专家 | 1 个技术域贯通 | 跨域 + 战略选型 |
| **业务理解** | 完成被分配任务 | 理解需求背景 | 参与业务讨论 | 推动业务决策 |
| **团队规模** | 独立贡献者 | 带 0-3 人 / 指导新人 | 带 5-15 人 / 主导项目 | 带 15-30+ 人 / 主导跨 BU |
| **影响力半径** | 团队内 | 跨小组 | 跨团队 | 跨 BU / 跨公司 |
| **决策半径** | 局部技术决策 | 模块架构 | 子系统 / 平台架构 | 企业级架构 |
| **跨团队协作** | 配合 | 推动 | 主导 | 发起 + 资源争取 |
| **业务沟通** | 与 TL 沟通 | 与业务方对接 | 与 PM 协商 | 与 VP 沟通 |
| **文化建设** | 遵守规范 | 局部改进 | 主导实践 | 建立文化 |
| **行业发声** | 无 | 内部分享 | 公开分享 / 写文章 | 行业标准 / 专利 |

## P5 → P6 的关键能力跃迁

**核心问题**：从「写代码」到「设计模块」。

**关键能力**：
- 能独立 hold 住一个完整模块（端到端：需求 → 设计 → 编码 → 部署 → 监控）
- 能在不参考他人代码的情况下，从零设计一个新模块
- 能在 Code Review 中给同事提有价值的意见
- 能在 oncall 中独立处理告警

**典型证据**：
- 主贡献 1-2 个完整模块
- 主贡献 1-2 个性能优化 / 重构项目
- 独立处理过 1-2 次生产事故

## P6 → P7 的关键能力跃迁

**核心问题**：从「模块专家」到「子系统 / 平台 owner」。

**关键能力**：
- 能主导一个技术方向（如「实时数据通道」），有 roadmap 思维
- 能在多个技术栈间做选型决策（不只懂一种）
- 能推动跨团队项目（不只是自己组内）
- 能培养 P5 / P6 同学
- 能在技术评审 / ADR 中给出有说服力的判断

**典型证据**：
- 主导 1-2 个跨团队项目
- 有 1-2 个被其他团队复用的产出（工具 / 平台 / 规范）
- 培养过 1-2 个同学到 P5 / P6
- 在技术社区 / 公开场合有发声

## P7 → P8 的关键能力跃迁

**核心问题**：从「技术专家」到「企业级架构师 / 平台 owner」。

**关键能力**：
- 能设计企业级数据栈（湖仓一体 / 实时 / AI 一体化）
- 能从「成本 / 风险 / 业务 / 团队」4 维度做技术选型
- 能推动跨 BU 协作（如数据中台 / 指标平台）
- 能影响组织的技术战略（3-5 年路线图）
- 能在公开场合代表公司技术品牌

**典型证据**：
- 主导 1 个企业级平台（被多 BU 使用）
- 主导 1 次跨 BU 技术演进（如「从 Hadoop 迁 Iceberg」）
- 培养出 1-2 个 P7
- 在 Apache / CNCF / 公开技术大会 / 行业白皮书 有贡献
- 主导 1 个跨 BU 数据治理 / 合规项目

## P8 → 数据架构师 的关键能力跃迁

**核心问题**：从「技术领导者」到「业务 + 战略 + 组织 领导者」。

**关键能力**：
- **业务翻译**：能听懂业务，翻译成数据架构（不被业务方「用」而能反向影响）
- **战略视野**：能看 3-5 年技术方向，决定今天的投入
- **组织影响**：能建文化、带 50+ 人、推动跨 BU 协作
- **行业影响**：能代表公司发声（开源 / 论文 / 演讲 / 专利 / 行业标准）
- **风险平衡**：能平衡技术 / 业务 / 合规 / 成本 / 团队 5 个维度

**典型证据**：
- 主导 1 个企业级数据中台 / 湖仓平台
- 主导 1 次企业级技术战略（CTO 级别）
- 培养出 1-2 个 P8
- 在 Apache 顶级项目 / SIGMOD / VLDB / 行业大会 有贡献
- 公司级技术品牌建设（行业分享 / 媒体曝光 / 开源项目）

## 关键工具：能力自评

每季度问自己 3 个问题：
1. **我做了什么独特的事**？—— 不是别人也能做而是我做的
2. **我影响了谁**？—— 团队 / 跨团队 / 跨公司 / 行业
3. **我下季度要补什么**？—— 1 个硬技能 + 1 个软技能
