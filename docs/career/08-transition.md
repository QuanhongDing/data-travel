# 跨公司转型（Transition）

> **核心定位**：P7+ 资深工程师的转型选择——大厂 / 独角兽 / 创业 / 海外 / 跨行业——每种转型都有成本与收益。

## 5 种转型路径

### 路径 1：大厂 → 大厂（同行业）

**典型场景**：
- 阿里 → 字节
- 腾讯 → 美团
- 字节 → 京东

**优势**：
- 平台对等 / 流程熟悉 / 业务相似
- 涨薪 20-40%
- 学习新公司的具体技术栈

**劣势**：
- 业务深度可能比原来浅
- 文化适应期 3-6 个月
- 资历清零（从 P7 重新开始）
- 人脉需要重建

**怎么判断是否该跳**：
- 涨薪 ≥ 30%
- 业务 / 团队 / leader 至少 2 项明显更好
- 不跳的话下家涨薪 / 业务 / title 至少 1 项明显更好

### 路径 2：大厂 → 独角兽（高成长）

**典型场景**：
- 阿里 P7 → 字节 2-2
- 美团 L7 → 小红书资深
- 腾讯 T11 → 滴滴 / 快手资深

**优势**：
- 业务快速增长 / 全栈机会 / 影响力大
- title 提升（独角兽 title 比大厂稀缺）
- 股权潜在收益
- 学习 0→1 业务

**劣势**：
- 体系不完善（自己需要顶上去）
- 加班多 / 不稳定
- 资历不一定被认可（独角兽可能 2-2 = 大厂 P6）
- 大厂光环丢失

**怎么判断**：
- 业务是否在快速增长（同比 / 环比）
- 创始人 / CXO 是否有大厂背景（决定天花板）
- 是否有股权 + 估值合理性

### 路径 3：大厂 → 创业公司（早期）

**典型场景**：
- 阿里 P7 → A 轮创业公司技术负责人
- 字节 2-2 → AI 创业公司 CTO

**优势**：
- 0→1 经历 / 全栈 / 影响力最大
- 股权（可能大）
- 距离创始人最近
- 学到「完整」的技术 / 业务 / 团队

**劣势**：
- 不稳定（公司可能死）
- 工资低（可能砍 30-50%）
- 加班极多
- 失败风险高（90% 创业公司 3 年内死）

**怎么判断**：
- 创始人是否连续成功 / 有信誉
- 业务是否在风口 + 有护城河
- 团队是否完整（CTO + 产品 + 销售）
- 你是否真的能 hold 住（不是 0→1 的人慎入）
- 现金储备 ≥ 18 个月

### 路径 4：大厂 → 外企（海外或中国外企）

**典型场景**：
- 阿里 → Microsoft / Google
- 字节 → Netflix
- 拼多多 → Stripe

**优势**：
- WLB / 工程师文化
- 国际化视野
- 高 base（特别是美企）

**劣势**：
- 职级对等难度大（阿里 P7 ≠ Google L5，可能降级到 L4）
- 业务深度可能浅
- 晋升慢
- 中国本土创新难

**怎么判断**：
- 你的能力是否能通过外企面试（算法 / 系统设计 / 行为面试）
- 你的职级映射（阿里 P7 / 字节 2-2 ≈ Google L5）
- 你的 WLB 偏好（高 / 中 / 低）
- 你的长期规划（海外 / 国内）

### 路径 5：跨行业（技术岗 → 行业岗）

**典型场景**：
- 互联网 → 金融（招行 / 平安）
- 互联网 → 政企（信通院 / 国家电网）
- 互联网 → 游戏（米哈游 / 网易）

**优势**：
- 行业壁垒带来差异化
- 长期稳定性（金融 / 政企）
- 业务更深入（行业 know-how）

**劣势**：
- 行业 know-how 需重学
- 技术更新慢
- 薪资可能下降（特别是金融 / 政企）

**怎么判断**：
- 你的长期偏好（互联网 / 行业）
- 你的家庭 / 城市选择（金融 / 政企 / 国企通常在特定城市）
- 行业前景（朝阳 / 成熟 / 夕阳）

## 转型决策的 3 大原则

### 原则 1：先想清楚「为什么跳」

**常见的 4 种理由**：
- ✓ 业务天花板到了
- ✓ leader 烂 / 团队烂
- ✓ 技术方向需要换
- ✓ 薪资 / title 明显提升

**常见的 4 种错误理由**：
- ❌ 同事跳了我也跳
- ❌ 听说那边更轻松
- ❌ 暂时不爽就跳
- ❌ 单纯被新公司 title 吸引

**如果理由不清晰，**不跳**—— 1-2 年后大概率会后悔。

### 原则 2：先拿 offer，再做决定

- 不要在「**想跳**」状态下裸辞
- 目标：在职 3-6 个月面试
- 拿到 2-3 个 offer 后对比

### 原则 3：入职前 1-2 个月要做「期望对齐」

- 入职前问清：团队 / 业务 / leader / 职级 / 薪资 / 期权
- 避免「入职后才发现不是说的那样」

## 转型的 5 大风险与应对

### 风险 1：水土不服

- **表现**：新公司文化 / 流程不适应
- **应对**：先 1-2 个月观察，不要「立竿见影」

### 风险 2：职级被低估

- **表现**：新公司给的职级低于你的实际能力
- **应对**：入职前明确职级 + 评估标准 + 1-2 年晋升时间表

### 风险 3：业务天花板

- **表现**：新公司业务在 2-3 年内到顶
- **应对**：面试时问业务的天花板 / 5 年规划

### 风险 4：人脉丢失

- **表现**：从大厂到小公司，行业人脉减少
- **应对**：保持技术博客 / 行业大会 / 校友会的活跃

### 风险 5：股权陷阱

- **表现**：股权无法兑现（公司被收购 / 倒闭 / 解禁期太长）
- **应对**：问清 4 年 vesting / 行权价 / 退出机制

## 转型后的「前 3 个月」关键动作

- **第 1 个月**：只听 / 只学 / 只问——不「立功」 / 不「改变」
- **第 2 个月**：找到 1-2 个「快速可赢」项目（小但可见）
- **第 3 个月**：交付快速可赢项目，建立信任
- **第 4-6 个月**：找到 1 个「差异化贡献」项目
- **第 6-12 个月**：推动 1 个「跨团队」项目
- **第 12-18 个月**：成为团队核心 / 主导 1-2 个方向

## 转型的「12-24-36 月」节奏

### 0-12 月：适应 + 做出 1 个亮点

- 学习新公司的技术栈 / 业务 / 流程
- 交付 1-2 个「快速可赢」项目
- 建立 1-2 个跨团队关系

### 12-24 月：建立 1 个护城河

- 主导 1 个关键项目
- 培养 1-2 个新人
- 1-2 次内部 / 外部分享

### 24-36 月：成为不可或缺

- 主导 1 个跨团队 / 跨 BU 项目
- 1 次晋升（P7→P8 / 2-2→3-1）
- 行业 / 社区发声

## 3 个真实转型案例

### 案例 1：阿里 P7 → 字节 2-2（1 年后）
- 理由：业务天花板到了，团队负责人不靠谱
- 准备：3 个月在职面试，5 家公司面试
- 结果：涨薪 35%，新公司业务更有前景
- 反思：准备充分，没踩坑

### 案例 2：美团 L8 → 米哈游资深（2 年后）
- 理由：想换到游戏行业
- 准备：6 个月在职面试，3 家公司
- 结果：涨薪 10% + 大量股权，新行业
- 反思：游戏行业 know-how 重学，1 年才 hold 住

### 案例 3：字节 2-2 → 创业公司 CTO（1 年后）
- 理由：想成为 0→1 选手
- 准备：找老 leader 聊 3 个月，深度调研 5 个方向
- 结果：薪酬砍 30% + 大量股权 + 压力大
- 反思：创业不适合所有人；压力极大但成长极快
