# Ch8 · AI 治理与安全

> **一句话定位**：AI 资产分级保密、防泄露、合规——**资深架构师必须守住底线，AI 资产不能泄露**。

## 画像映射

本章对应 **核心职责⑥ AI 资产分级保密与防泄露体系** + **加分项（等保 2.0/3.0 合规）**：

- 黑盒化资产封装、细粒度权限管控、全链路操作审计、输出端防泄露
- 数据安全（脱敏 / 加密 / 分类分级）、权限管控（RBAC / ABAC）、审计日志
- 防泄露（DLP / 提示词注入防御）、合规（等保 2.0/3.0 / GDPR / 个保法）
- 国产化适配

> P7 会"做权限"，P8 会"做审计"，**资深架构师会让 AI 系统"通过等保 3.0 评审"**——守住合规底线，承载业务上线。

## 本章要回答的核心问题

1. **AI 资产怎么分级分类？** 公开 / 内部 / 机密 / 绝密——四象限分类法与对应保护措施？
2. **数据脱敏与加密怎么做？** 静态脱敏 / 动态脱敏 / 差分隐私 / 同态加密——不同场景下的取舍？
3. **细粒度权限怎么设计？** RBAC / ABAC / 字段级权限 / 行级权限——如何在 RAG 召回与 LLM 生成中落地？
4. **Prompt 注入与越狱怎么防御？** 输入侧过滤 / 系统提示加固 / 输出侧校验——构建纵深防御？
5. **DLP（数据防泄露）怎么设计？** 输出端关键词检测、敏感实体识别（身份证 / 银行卡 / 手机号）、二次确认机制？
6. **等保 2.0/3.0 合规怎么落地？** 物理安全 / 网络安全 / 主机安全 / 应用安全 / 数据安全——五级保护的具体要求？
7. **全链路审计怎么做？** 访问日志、调用日志、生成日志、用户反馈——可追溯、可回放、可定责？
