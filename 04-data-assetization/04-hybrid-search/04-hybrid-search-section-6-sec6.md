### 6.1 Algolia「**混合检索 SaaS**」8+ 年演进（2016-2024）

**背景（Why）**

Algolia 2016 年面临**电商搜索**挑战：
- **百万级商品**——**传统关键词搜索**——**「**召回差**」**
- **「**语义搜索**」**——**向量搜索**——**「**速度慢**」**
- **需要「**关键词 + 语义**」**——**双路**

**触发点（What）**

2016 年**Algolia 上线混合检索**（[Algolia 博客 2017]）——**目标**：「**毫秒级 + 关键词 + 语义**」。

**详细做法（How）**

Algolia 混合检索的**5 大核心组件**：

1. **BM25 关键词检索（基础）**
   - 关键设计：**经典 BM25**——**关键词 + 词频 + 文档长度**
   - 关键能力：**毫秒级**——**亿级文档**

2. **Embedding 向量检索（核心）**
   - 关键设计：**自研 Embedding**——**预训练 + 微调**
   - 关键能力：**语义理解**——**同义词 / 上下位**

3. **RRF 融合（核心创新）**
   - 关键设计：**Reciprocal Rank Fusion**——**BM25 + 向量 + 个性化**——**3 路**
   - 关键能力：**权重自适应**——**不同业务不同权重**
   - 关键代码：
     ```python
     # Algolia 混合检索 RRF
     def hybrid_search(query, top_k=10):
         # 1. BM25 检索
         bm25_results = bm25_search(query, top_k=100)
         # 2. 向量检索
         vector_results = vector_search(query, top_k=100)
         # 3. 个性化重排
         personalized_results = personalize(query, bm25_results, vector_results)
         # 4. RRF 融合
         fused = rrf_fusion(
             [bm25_results, vector_results, personalized_results],
             weights=[0.3, 0.4, 0.3]
         )
         return fused[:top_k]
     ```

4. **Cohere Reranker 精排**
   - 关键设计：**Cohere Rerank 3**——**粗排后精排**——**精准度 +25%**
   - 关键能力：**100 候选**——**精排到 top 10**

5. **个性化（核心创新）**
   - 关键设计：**用户行为**——**个性化重排**
   - 关键能力：**CTR 提升 30%**

**Algolia 混合检索关键数字**（[Algolia 2017-2024 公开数据]）：

| 指标 | 改前 | 改后 | 提升 |
| --- | --- | --- | --- |
| **召回率 Recall@10** | 60% | 90%+ | **30% 提升** |
| **CTR** | 基线 | +30% | **30%** |
| **响应延迟** | 200ms | 50ms | **4 倍** |
| **日均查询** | 1 亿+ | 100 亿+ | **100 倍** |
| **客户数** | 1 万 | 17000+ | **1.7 倍** |
| **文档库** | 100 万 | 100 亿+ | **1000 倍** |

**具体数字（How much）**

- 团队规模：Algolia 200+ 人
- 关键数字（[2024 公开数据]）：
  - **100 亿+ 日均查询**
  - **100 亿+ 文档**
  - **17000+ 客户**
- 业务影响：覆盖**全球电商 / SaaS / 媒体**

**失败教训**

- 早期**纯 BM25**——倒逼**「**向量**」**
- **纯向量慢**——倒逼**「**BM25 + 向量融合**」**
- **「**权重不优**」**——倒逼**「**A/B 测试**」**

### 6.2 字节跳动「**电商混合检索**」4+ 年（2020-2024）

**背景（Why）**

字节 2020 年面临**电商搜索**挑战：
- **抖音 / TikTok 电商**——**百万级商品**——**传统搜索差**
- **「**语义 + 关键词**」**双路召回

**触发点（What）**

2020 年**字节启动混合检索**（[ArchSummit 2021]）——**目标**：「**「**以图 + 文字**」**——**找同款**」。

**详细做法（How）**

字节电商混合检索的**5 大创新**：

1. **BM25 + BGE-M3 融合**
   - 关键设计：**BM25 关键词** + **BGE-M3 多模态向量**——**2 路召回**
   - 关键代码：
     ```python
     # 字节 BM25 + BGE-M3
     bm25 = BM25Okapi()
     vector_index = Milvus()
     vector_index.load("bge_m3_embeddings")
     
     def retrieve(query):
         # 1. BM25
         bm25_results = bm25.search(query, top_k=100)
         # 2. BGE-M3 向量
         query_emb = bge_m3.encode(query)
         vector_results = vector_index.search(query_emb, top_k=100)
         # 3. 合并
         return rrf_merge(bm25_results, vector_results)
     ```

2. **多模态 Embedding（BGE-M3）**
   - 关键设计：**BGE-M3**——**支持 100+ 语言**——**多模态**
   - 关键能力：**亿级商品**——**毫秒级**

3. **RRF 融合（核心创新）**
   - 关键设计：**多路 RRF**——**BM25 + 向量 + 个性化**

4. **Cohere Rerank 3 精排**

5. **个性化（CTR）**
   - 关键设计：**用户行为**——**CTR 优化**——**个性化重排**

**字节电商混合检索关键数字**（[ArchSummit 2021]）：

| **Recall@10** | 60% | 92%+ | **32% 提升** |
| **CTR** | 基线 | +35% | **35%** |
| **响应延迟** | 200ms | 60ms | **3.3 倍** |
| **日均查询** | 5000 万 | 50 亿+ | **100 倍** |

**具体数字（How much）**

- 团队规模：字节电商搜索团队 50+ 人

  - **50 亿+ 日均查询**
