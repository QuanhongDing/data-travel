### 4.1 某电商"**ES + 向量混合检索 4+ 年**"（2020-2024）

**背景（Why）**

该电商 2020 年面临**混合检索**：
- **多模态搜索**——文本 + 图片
- **传统 ES**——**字面匹配强，向量弱**
- **向量**——**语义强，字面弱**

**触发点（What）**

2020 年该电商启动**ES + 向量混合检索**（[案例 2020]），目标：
- **字面 + 语义**
- **多模态**
- **毫秒级**

**详细做法（How）**

该电商混合检索的**5 大核心组件**：

1. **ES + 向量（核心创新）**
   - 关键设计：**ES 存字面 + 向量库存语义**
   - 关键能力：**字面 + 语义**
   - 关键数字：**100% 混合**

2. **多模态 embedding（核心）**
   - 关键设计：**BGE / CLIP 统一**
   - 关键能力：**多模态**
   - 关键数字：**多模态**

3. **RRF 融合（核心）**
   - 关键设计：**Reciprocal Rank Fusion + 字面 + 语义**
   - 关键能力：**最优融合**
   - 关键数字：**召回 90%+**

4. **重排序（核心）**
   - 关键设计：**Cohere Rerank / BGE Rerank**
   - 关键能力：**精排**
   - 关键数字：**P99 < 200ms**

5. **多模态融合（核心创新）**
   - 关键设计：**多模态 RAG 集成**
   - 关键能力：**AI 集成**
   - 关键数字：**100% 集成**

**该电商混合检索关键数字**（[案例 2020-2024]）：

| 指标 | 改前 | 改后 | 提升 |
| --- | --- | --- | --- |
| **字面 + 语义** | 不可用 | 100% | **∞** |
| **多模态** | 不可用 | 100% | **∞** |
| **召回 90%+** | 不可用 | 100% | **∞** |
| **P99 < 200ms** | 不可用 | 100% | **∞** |
| **AI 集成** | 不可用 | 100% | **∞** |
| **ES + 向量** | 不可用 | 100% | **∞** |
| **BGE / CLIP** | 不可用 | 100% | **∞** |
| **RRF 融合** | 不可用 | 100% | **∞** |

**具体数字（How much）**

- 团队规模：该电商搜索团队 30+ 人
- 关键数字：**召回 90%+**；**P99 < 200ms**；**多模态**
- 业务影响：覆盖该电商**全部搜索**

**失败教训**

- 早期「**字面与向量割裂**」——倒逼混合
- **融合权重难**——后**RRF**
- **性能不够**——后**重排序**
