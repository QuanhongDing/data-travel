**详细做法（How）**

Meta Presto 联邦查询的**5 大核心组件**：

2. **「**CBO 优化**」**（核心）
3. **「**多租户**」**（核心）
4. **「**资源隔离**」**（核心）
5. **「**统一 SQL**」**（核心）
