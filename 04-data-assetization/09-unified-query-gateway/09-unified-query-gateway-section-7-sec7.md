## 7. 与其他方法对比

### 7.1 对比维度（评分 1-5）

| 维度 | ETL 同步 | 数据复制 | 联邦查询 | 统一查询网关 |
| --- | --- | --- | --- | --- |
| 数据新鲜度 | 2 | 3 | **5** | **5** |
| 跨源 JOIN | 3 | 4 | 4 | **5** |
| 性能 | **5** | **5** | 3 | 4 |
| 存储成本 | 2 | 2 | **5** | **5** |
| 灵活性 | 2 | 2 | 4 | **5** |
| AI 集成 | 3 | 3 | 3 | **5** |
| 工程复杂度 | 3 | 3 | 4 | 4 |

### 7.2 决策树

```
[需要跨源查询吗？]
   │
   ├── 否 → 直接查单一数据源
   │
   ├── 是 → [实时性要求？]
   │          │
   │          ├── 高 → 联邦查询（Trino）★
   │          │
   │          └── 低 → ETL 同步 / 数据复制
   │
   └── [需要 AI 集成？]
          │
          ├── 否 → Trino / Presto
          └── 是 → Trino + AI Connector
```

### 7.3 组合使用

- **统一查询网关 + RAG**：跨结构化 + 向量 + KG 联邦检索。
- **统一查询网关 + 数据目录**：跨源元数据统一。
- **统一查询网关 + 数据 API 网关**：联邦查询结果 API 化。
- **统一查询网关 + Agent**：Agent 工具调用统一查询。
