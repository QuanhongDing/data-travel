### 2.1 Databricks"**Lakehouse + Vector Search 4+ 年**"（2020-2024）

**背景（Why")**

Databricks 2020 年面临**Lakehouse + Vector Search**：
- **AI 与 Lakehouse 割裂**——**AI 在 Python**
- **数据出仓**——**AI 计算**
- **EB 级**——**RAG 集成**

**触发点（What")**

2020 年 Databricks 推出**Lakehouse + Vector Search**（[Databricks 2020]），目标：
- **Lakehouse 上做向量**
- **RAG 直接用**
- **EB 级**

**详细做法（How")**

Databricks Vector Search 的**5 大核心组件**：

1. **Delta Lake + Vector（核心创新）**
   - 关键设计：**Delta Lake 表存向量**
   - 关键能力：**湖仓**
   - 关键数字：**EB 级**
   - 关键示意：
     ```python
     # Delta Lake + Vector Search
     from databricks.vector_search import VectorSearchIndex
     index = VectorSearchIndex(
         delta_table='rag.docs',
         embedding_model='bge-large-en',
         index_type='HNSW',
     )
     results = index.similarity_search(query='什么是数据中台', k=5)
     ```

2. **多模态 embedding（核心）**
   - 关键设计：**Databricks 自研 embedding**
   - 关键能力：**多模态**
   - 关键数字：**多模态**

3. **RAG 集成（核心）**
   - 关键设计：**与 LlamaIndex / LangChain 集成**
   - 关键能力：**RAG**
   - 关键数字：**100% 集成**

4. **水平扩展（核心）**
   - 关键设计：**自动 sharding**
   - 关键能力：**PB / EB**
   - 关键数字：**PB / EB**

5. **AI 集成（核心创新）**
   - 关键设计：**与 LangChain / LlamaIndex 集成**
   - 关键能力：**AI**
   - 关键数字：**100% 集成**

> **本节小结**：
> - 4 个真实案例（Databricks / 字节 / 阿里 / Pinecone）印证：**向量湖不是「**向量库 + 湖**」，是「**Iceberg + Milvus + 多模态 + RAG 集成 + SaaS**」**5 件套**。
