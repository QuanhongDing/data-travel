## 5. 前沿演进（AI 时代）

### 5.1 LLM/Agent 时代的演进方向

- **AI 辅助 Make-or-Buy**：LLM 推荐选项 + TCO 估算 + 风险评估。
- **Decision Intelligence Platform**：组织级 Make-or-Buy 决策图谱。
- **Build-vs-Buy-as-Code**：决策即代码（用 DSL 表达，自动生成决策报告）。
- **AI Agent 自研门槛降低**：低代码 / Agent 框架让自研更快更便宜。
- **基础模型 API + 微调**：基础模型 API（采购）+ 垂直微调（自研）成为新模式。
- **Agent Marketplace**：AI Agent 市场（如 OpenAI GPT Store）让采购更快。
- **AI Governance 自研**：合规 / 安全 / 隐私等强监管领域回归自研。
- **边缘 AI 自研**：实时性要求高的场景必须自研（边缘推理）。

### 5.2 与 RAG / 向量库 / GraphRAG 的结合

- **Make-or-Buy + RAG**：决策时 RAG 检索类似历史决策 + ADR。
- **Make-or-Buy + KG**：把所有 Make-or-Buy 决策建成 KG——可推理「某类组件的最佳决策」。
- **Make-or-Buy + GraphRAG**：跨组件的依赖推理（如「自研 X 是否影响 Y」）。

### 5.3 学术与工业最新进展（2024-2025）

- **2024**：AI Agent 框架爆发（LangChain、AutoGen、CrewAI、Semantic Kernel）。
- **2024**：OpenAI GPT Store 上线，AI Agent 采购生态成熟。
- **2024**：Anthropic / Google / Meta 发布基础模型 + 微调工具链。
- **2024**：企业级 AI 采购 / 治理框架成熟（如 Microsoft Copilot Studio）。
- **2025**：Decision Intelligence（Gartner 顶级趋势）成为 Make-or-Buy 决策平台。
- **2025**：AI 自研 vs API 选择成为新热点。

### 5.4 未来 3-5 年趋势

- **AI 降低自研门槛**：基础模型 + Agent 框架让中小企业自研 AI 应用成为可能。
- **AI 抬高采购复杂度**：模型选型 + Prompt 工程 + 微调 + 合规 = 多维决策。
- **Decision Intelligence 平台化**：组织级 Make-or-Buy 决策图谱。
- **Build-vs-Buy-as-Code**：决策自动化 + 可审计。
- **AI Constitutional 决策**：用「宪法」约束 Make-or-Buy 决策（核心能力必须自研）。
- **边缘 AI 自研**：实时 / 隐私 / 离线场景强制自研。
