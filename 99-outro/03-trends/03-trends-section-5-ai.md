## 5. AI 治理与监管

### 5.1 AI 治理的核心问题

#### 问题 1：合规与监管

- 欧盟 AI Act（2024 通过）
- 中国《生成式 AI 服务管理办法》（2023）
- 美国 EO 14110 / 行政命令
- 信通院《AI 治理框架》
- 等保 2.0 / 3.0

#### 问题 2：内容安全

- 幻觉（Hallucination）
- 偏见（Bias）
- 版权（Copyright）
- 隐私（Privacy）
- 仇恨言论 / 暴力 / 歧视

#### 问题 3：使用安全

- Prompt 注入
- 数据外泄
- 模型中毒
- 对抗攻击

#### 问题 4：责任与审计

- 谁为 AI 输出负责？
- AI 决策如何追溯？
- 出问题后如何复盘？
- 损失如何分担？

### 5.2 AI 治理的 5 个层级

```
L1：合规层
   - 法规 / 标准 / 备案
   - 数据来源合规

L2：内容层
   - 输出审查
   - 内容过滤
   - 幻觉检测

L3：使用层
   - 权限管理
   - 限流降级
   - 输入验证

L4：技术层
   - Prompt 注入防护
   - 模型可解释性
   - 审计日志

L5：组织层
   - 治理委员会
   - 应急预案
   - 红蓝对抗
   - 持续监控
```

### 5.3 AI 治理的未来 3 年趋势

#### 趋势 1：从"原则性框架"到"可量化的合规标准"

- 过去：AI 治理是"原则性指南"
- 未来：AI 治理是"可量化、可审计、可追溯"的标准

#### 趋势 2：从"事后审查"到"事前 + 事中 + 事后"全链路

- 过去：AI 上线后才审查
- 未来：AI 设计阶段就考虑治理（治理左移）

#### 趋势 3：从"单点工具"到"治理平台"

- 过去：每个团队各自做治理
- 未来：中央治理平台（统一规则、统一审计、统一响应）

#### 趋势 4：从"技术治理"到"技术 + 组织 + 文化"立体治理

- 技术治理：工具 / 平台 / 自动化
- 组织治理：委员会 / 红蓝对抗 / 应急机制
- 文化治理：全员意识 / 培训 / 价值观
