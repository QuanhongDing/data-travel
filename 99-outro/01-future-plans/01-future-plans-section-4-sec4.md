## 4. 关键行动项

### 4.1 立即行动（本周）

- [ ] 把你的 LinkedIn / 简历更新到"AI 时代数据架构师"定位
- [ ] 给自己的 Mentor 发一条微信，约一次季度交流
- [ ] 把"过去 12 个月做的最有价值的决策"写一份 1000 字复盘
- [ ] 列出 3 个"想深度学习的 AI 课题"（RAG / Agent / 向量 / 治理任选）

### 4.2 3 个月行动

- [ ] 完成一个 RAG / 智能体 Demo（哪怕是个人项目）
- [ ] 写 3 篇公开技术博客（每篇 1500+ 字）
- [ ] 主导一次跨团队的 ADR 评审
- [ ] 申请一次公开分享（公司内 / Meetup / 大会 任一）

### 4.3 1 年行动

- [ ] 主导一个 0→1 的 AI 项目，跑通业务闭环
- [ ] 培养 1-2 个 P5/P6 晋升到 P6/P7
- [ ] 建立一个 5 人跨职能小组（含数据 / 算法 / 业务 / 产品）
- [ ] 完成一次大型技术决策（自研 vs 采购 / 集中 vs 联邦 / 上云 vs 下云 任一）

### 4.4 3 年行动

- [ ] 成为某个领域公认的内外部专家（在 GitHub / 技术大会 / 行业报告 留名）
- [ ] 主导一次组织变革（团队重组 / 中台建设 / 治理升级 任一）
- [ ] 完成一次跨 BU / 跨公司的影响力输出（开源贡献 / 行业标准 / 公开演讲）
- [ ] 完成 P7 → P8 / 资深 → 准资深 的跃迁

### 4.5 年度 OKR 模板（可直接抄）

#### O1：成为 AI 时代数据架构领域的内部公认专家

- KR1：完成 3 个 RAG / 智能体项目，跑通业务闭环（O：业务价值 + 影响力）
- KR2：写 6 篇公开技术博客，每篇 ≥ 1500 字（O：技术品牌）
- KR3：在 2 次以上行业大会 / Meetup 上发表演讲（O：行业影响力）

#### O2：带领团队完成从"集中式中台"到"AI 原生数据栈"的演进

- KR1：完成数据语义层（Semantic Layer）的引入与推广，覆盖 50% 核心指标
- KR2：完成 1 个 AI 治理框架的落地（含分级保密 / 全链路审计 / 输出端防泄露）
- KR3：培养 2 名 P5/P6 晋升到 P6/P7

#### O3：建立"业务 + 数据 + 算法"三方协同机制

- KR1：建立跨部门数据治理委员会，月度例会
- KR2：建立"业务需求 -> 数据能力"的反向映射清单，覆盖 80% 核心业务场景
- KR3：建立"数据能力 -> 业务结果"的度量与回流闭环
