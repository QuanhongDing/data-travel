## 7. 推荐行动 / 推荐阅读

### 7.1 推荐行动清单

#### 立即（本周）

- [ ] 把个人定位调整为"AI 时代数据架构师"，更新 LinkedIn / 简历 / GitHub
- [ ] 约 3 个同 level / 高一 level 的 Mentor 做一次交流
- [ ] 把过去 12 个月做的"最有价值的 3 个决策"写成 3 份 ADR

#### 1 个月内

- [ ] 完成一个 RAG / 智能体 / 知识图谱 个人 Demo
- [ ] 写第 1 篇公开技术博客
- [ ] 加入 1 个开源项目（哪怕只是 issue 回复）

#### 3 个月内

- [ ] 完成 1 次公开技术分享（公司内 / Meetup / 大会）
- [ ] 主导 1 次跨团队 ADR 评审
- [ ] 完成 1 个 AI 治理 / 数据合规培训（信通院 / DAMA / CDA 任一）

#### 6 个月内

- [ ] 主导 1 个 0→1 的 AI 项目
- [ ] 培养 1-2 个下属晋升
- [ ] 建立 1 个跨职能小组

#### 1 年内

- [ ] 完成 P7 → P8 / 资深 → 准资深 的跃迁（如果你还没到）
- [ ] 在行业内建立"内外部公认"的专家形象
- [ ] 主导 1 次组织级变革

### 7.2 推荐阅读

#### 必读书（顶层认知）

- 《第一性原理》（埃隆·马斯克传）—— 培养"从本质出发"的思维
- 《长期主义》（罗杰·马丁）—— 培养"长期 vs 短期"的平衡感
- 《原则》（瑞·达利欧）—— 培养"决策与组织"的工作框架
- 《奈飞文化手册》—— 培养"高绩效文化"的实操
- 《Data Mesh》（Zhamak Dehghani）—— 数据架构的下一代范式
- 《Designing Data-Intensive Applications》（Martin Kleppmann）—— 数据系统的圣经

#### 推荐书（专业深度）

- 《Knowledge Graphs》（Aidan Hogan 等）—— 知识图谱的体系化教材
- 《Designing Machine Learning Systems》（Chip Huyen）—— ML 系统的工程化
- 《AI Engineering》（Chip Huyen）—— LLM 应用的工程化
- 《数据中台实战》（企业级数据中台白皮书）—— 中国本土实践
- 《Building the Data Lakehouse》（Bill Inmon 等）—— Lakehouse 架构

#### 推荐专栏 / Newsletter

- The Pragmatic Engineer（高级软件工程实战）
- Byte Byte Go（系统设计深度拆解）
- Import AI（AI 产业前沿）
- The AI Engineer（LLM 应用工程化）
- Papers With Code（学术 + 工程结合）

#### 推荐开源项目（边用边学）

- LangChain / LlamaIndex（LLM 应用框架）
- dbt / Cube（数据转换 + 语义层）
- Apache Airflow / Dagster / Prefect（数据编排）
- Milvus / Weaviate / Qdrant（向量数据库）
- Neo4j / NebulaGraph（图数据库）
- OpenTelemetry / Grafana / Prometheus（可观测）

#### 推荐会议 / 社区

- 国内：DataFun、AICon、QCon、ArchSummit、DTCC
- 国际：Strata Data Conference、Spark Summit、KubeCon、ODSC、Ray Summit
- 社区：GitHub / Hugging Face / LangChain / dbt / Data Mesh Learning
