## 3. 架构演进

### 3.1 V1.0：单产品阶段（2012–2015）

**形态**：

```
[业务] → [MySQL + MongoDB] → [Hadoop + Hive] → [Tableau]
```

**问题**：

- 数据孤岛，今日头条、抖音、悟空问答各自一套。
- 实时能力弱，推荐系统 AB 实验难以分钟级。

**教训**：早期数据栈能跑通，但不够"工程化"。

### 3.2 V2.0：AB 实验平台化（2015–2018）

**关键事件**：

- 2015：今日头条 AB 实验平台 V1 上线，覆盖所有推荐场景。
- 2016：抖音上线，AB 平台 V2，支持"亿级流量稳定分流"。
- 2017：AB 平台支持"互斥分层 + 流量调拨"。
- 2018：AB 平台对外，**火山引擎 AB 平台**（A/B 实验）成为 ToB 产品。

**核心能力**：

- **流量分桶**：基于用户 ID 哈希 + 互斥分层。
- **实时分流**：毫秒级决策。
- **统一指标**：所有 AB 实验接入统一指标平台。
- **置信度评估**：自动计算显著性。

### 3.3 V3.0：ByteHouse + DataLeap（2017–2020）

**关键事件**：

- 2017：ByteHouse V1（基于 ClickHouse 19.x 自研改造）。
- 2018：DataLeap V1（数据集成 + 数据开发）。
- 2019：ByteHouse V2（针对字节场景优化，分片、并发、副本）。
- 2020：ByteHouse V3（支持存算分离、云原生）。

**ByteHouse 关键改进**：

- **向量化执行**：相比 ClickHouse 提升 30%+ 性能。
- **分布式优化**：相比 ClickHouse 提升 10x+ 规模。
- **字节场景定制**：针对推荐场景的特征查询、向量检索。

### 3.4 V4.0：Lakehouse + 实时（2021–2023）

**关键事件**：

- 2021：基于 Iceberg + Spark/Flink 的 Lakehouse 架构。
- 2022：实时数仓 + 实时特征平台。
- 2023：Feature Store 平台化，覆盖推荐 / 广告 / 搜索。

**Lakehouse 关键能力**：

- **Iceberg 表格式**：ACID、Schema Evolution、Time Travel。
- **存算分离**：存储在 S3 / HDFS，计算在 Spark / Flink。
- **流批一体**：同一份代码同时跑批 + 流。

### 3.5 V5.0：火山引擎商业化（2019–2024）

**关键事件**：

- 2019：火山引擎成立，字节 ToB 商业化平台。
- 2020：火山引擎数据中台对外销售。
- 2021：ByteHouse 公有云版发布。
- 2022：火山引擎 + 抖音集团 + TikTok 三大业务板块成型。
- 2024：火山引擎大模型平台 + 字节豆包大模型对外服务。

**火山引擎核心产品**：

- **数据中台**：DataFinder（数据集成）+ DataLeap（数据开发）+ DataWind（BI）。
- **ByteHouse**：公有云版 OLAP。
- **AB 平台**：商业版 A/B 测试。
- **智能推荐**：基于字节推荐经验的产品。
- **大模型平台**：基于豆包 + 一站式 AI 服务。

### 3.6 V6.0：AI Native 数据栈（2023–2025）

**关键事件**：

- 2023：豆包大模型发布。
- 2024：扣子（Coze）智能体平台发布。
- 2025：豆包 1.5 Pro + 多模态，数据栈向 AI Native 全面演进。

**AI Native 数据栈关键能力**：

- **数据 → 知识**：结构化数据自动转化为大模型可消费的知识。
- **特征 → Agent**：特征平台成为 Agent 工具集。
- **指标 → Agent**：指标 API 成为 Agent Function Call。
- **AB → Agent**：AB 实验成为 Agent 自动决策工具。
